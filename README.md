# Jarvis Reader

在 Obsidian 中阅读 EPUB，将摘录和感想保存为 Markdown，并关联、提炼为知识笔记。· [English](./README.en.md)

当前版本：**1.4.6**。本版支持独立安装词典，修复了操作提示和主题显示问题，并补充安装说明与许可声明。[发布说明](./docs/releases/1.4.6.md) · [GitHub Releases](https://github.com/lrb1019/jarvis-reader/releases)。

## 功能

| 功能 | 使用方式 |
| --- | --- |
| 书架 | 网格／列表浏览；按文件名、EPUB 原始书名和作者搜索；筛选、排序与阅读进度 |
| 阅读 | 双击书籍打开并恢复位置；调整字号、行距、字间距、缩进、宽度及分页／滚动方式 |
| 高亮与笔记 | 选中文本后右键操作；一个摘录可有多条感想和关联链接 |
| 读书笔记 | 每本书对应一份读书笔记，使用稳定块 ID 定位片段；不为每条高亮创建文件 |
| 知识笔记 | 将选定片段提炼为知识笔记，保留原文、全部感想和来源；再次提炼时优先打开已有笔记 |
| 英语辅助 | 本地 ECDICT 释义、主动 AI 翻译、手动收藏单词和短语 |
| 阅读统计 | 自动计时、手动补录、周／月／年图表与阅读排行 |

在阅读侧栏切换目录、书签和笔记，在书卡菜单中管理书籍状态、评分、日期、标签、封面和删除操作。选中文字后需右键打开操作菜单；普通 Markdown 文件不提供全局查词。插件没有独立单词本或复习系统。

## 安装与升级

### BRAT

在 BRAT 中添加 `lrb1019/jarvis-reader`，安装 GitHub 上的正式版本，之后也可通过 BRAT 检查更新。开发分支中的改动不一定已经发布。

### 手动安装

从 [Releases](https://github.com/lrb1019/jarvis-reader/releases) 下载对应版本的插件 ZIP，解压到仓库的 `.obsidian/plugins/jarvis-reader/`，然后在「设置 → 第三方插件」启用。运行文件应直接放在该目录下，不要再套一层文件夹。

- **1.4.5**：完整 ZIP 包含运行文件、`dictionaries/ecdict/` 和第三方声明。
- **1.4.6 及更新版本**：插件 ZIP 包含 `main.js`、`manifest.json`、`styles.css`、`LICENSE`、`THIRD_PARTY_NOTICES.md`；词典改为独立 ZIP。仅安装三个运行文件即可阅读和记笔记；离线查词需要另外安装词典。

升级前备份笔记与插件数据，阅读对应版本的发布说明。替换程序文件时，请保留 `data.json`、`index/`、`cache/`、`logs/`、`pending/`、`backups/`、整个 `dictionaries/` 及用户笔记。不要先删除整个插件目录。更新后重载插件或重启 Obsidian。自定义 Obsidian 配置目录的完整兼容性尚未验收。

### 独立词典安装

1. 从本项目正式 Release 下载 `jarvis-reader-ecdict-*.zip`，无需解压。
2. 打开「Jarvis Reader 设置 → 词典与词卡 → 导入词典包」，选择 ZIP。
3. 等待 26 个分片校验并保存完成，状态显示「已安装」后即可离线查询。

已有的旧版词典可继续使用，无需重新导入。导入失败时保留原词典。插件会分别提示未安装、资源不完整、损坏或未收录，不会因此自动调用 AI，也不会改动收藏词条和笔记。词典导入目录和安装记录保存在插件的 `dictionaries/` 下，更新时应保留。

词典包约 18 MB，解压后约 90 MB。首次导入需要额外空间，已有资源目录会保留。包内含来源、内容版本、SHA-256 清单和 ECDICT 的 MIT 许可。同名 `.sha256` 可核对下载完整性；校验不是发布者身份认证，请只使用本项目正式资源。

## 开始阅读

1. 在插件设置中指定书籍文件夹，放入 EPUB；留空时书架扫描整个仓库。
2. 双击书籍打开，右上角可添加书签、打开本书笔记和调整阅读设置。
3. 选中原文并右键，创建高亮、感想或离线查询。
4. 点击有感想的标记打开笔记卡，追加感想或用 `[[笔记名]]` 关联已有内容；单条感想的更多菜单提供编辑和删除。
5. 点击灯泡，将片段提炼为知识笔记；通过来源链接返回读书笔记或 EPUB 原文。

新建笔记使用 Markdown 模板，已有笔记不会被批量替换。在仓库内重命名或移动文件时，关联会同步更新；删除文件、移出仓库或修复历史断链时，不能保证自动找回。请保留稳定块 ID，删除或改写它会影响原文定位。

| 文件夹设置 | 默认值 | 用途 |
| --- | --- | --- |
| 书籍文件夹 | 留空 | 筛选书架中的 EPUB |
| 读书笔记 | `Reading Notes` | 每本书的 Markdown 摘录与感想 |
| 知识笔记 | `Knowledge Notes` | 主动提炼的独立笔记 |
| 封面 | `Cover` | 上传的自定义图片 |

四个目录都使用仓库相对路径，可分别设置。保存时可以创建缺失目录，修改设置不会自动移动已有文件。删除书籍默认保留读书笔记和知识笔记。补录阅读时长按指定日期累加，用于补充未被自动记录的阅读时间，不会覆盖整本书的时长。

## 联网与隐私

| 操作 | 目的地及数据 |
| --- | --- |
| 本地阅读、摘录、离线释义 | 读取仓库内 EPUB、Markdown、索引和已安装词典；离线释义不请求翻译服务 |
| 主动 AI 翻译或设置中的 API 测试 | 请求所配置的基础地址，发送选文／必要上下文或测试词及访问密钥；不发送整本书、整章或无关笔记 |
| 点击单词发音 | 默认向 `dict.youdao.com` 发送词语和口音参数；也可配置其他地址或在设置中关闭发音。失败后回退浏览器／系统语音，其联网行为取决于所选语音引擎 |
| 点击词典下载页链接 | 浏览器访问 GitHub；插件不在后台自动下载或安装词典 |

当前提供的翻译预设包括 OpenAI、DeepSeek、Google Gemini、智谱、通义、Kimi 和 MiniMax，也允许自定义服务。**请求实际发送到所配置的基础地址，协议名称不代表接收方**；例如当前 Anthropic 格式预设使用 DeepSeek 兼容地址。请核对设置，服务商可能需要单独账号、API 密钥并产生费用。所选服务商按其隐私规则处理请求。

API 密钥随设置保存在插件 `data.json` 中，当前未使用独立加密密钥库。分享配置、日志、截图或备份前应移除密钥；不要上传整个插件数据目录。书籍内的外部资源、手动打开的外链，以及其他插件，也可能各自联网。

| 数据位置（相对插件目录，Markdown 除外） | 内容 |
| --- | --- |
| `data.json` | 设置、API 配置、阅读位置、进度、书签及计时 |
| 用户指定的 Markdown 文件夹 | 摘录正文、全部感想、关联与独立知识笔记 |
| `index/highlights.json` | 稳定片段身份、书籍／笔记路径、颜色、章节与 EPUB CFI |
| `index/word-assets.json` | 收藏词条、释义与来源 |
| `dictionaries/` | 本地词典、导入资源与安装记录 |
| `cache/`、`logs/`、`pending/`、`backups/` | 缓存、审计、未完成事务与恢复材料 |

笔记正文以 Markdown 为准，但仅凭 Markdown 无法重建丢失的 EPUB CFI 定位信息。请同时备份笔记和索引。

## 兼容性与限制

- 1.4.6 暂限桌面版 Obsidian `1.14.5` 或更新版本，实机验证在 macOS 上的 Obsidian `1.14.5` 中完成。移动端尚未验证，因此暂不开放移动端安装；历史已发布版本不改。
- 已验证三个运行文件的干净安装，以及 BRAT 从 `1.4.5` 升级到 `1.4.6`。完整主题覆盖、插件市场安装、其他 BRAT 升级路径、真实同步冲突和强制终止进程后的表现尚未全部验证。详见[发布说明](./docs/releases/1.4.6.md)。
- Claudian 禅模式的布局适配是可选功能，依赖其内部 CSS，可能影响其他分栏或遮挡底部正文。Claudian 不是阅读功能的必需依赖。
- 许可分发核对与完整文本见[第三方声明](./THIRD_PARTY_NOTICES.md)。其中 react-reader 的包信息与许可文件差异如实保留，并同时携带 ISC 与 Apache-2.0 条款；不宣称上游授予任选双许可。本项目尚未申请或通过插件市场审核。

## 开发与反馈

使用 Node.js 24 或更新版本：

```sh
npm ci
npm run verify
npm run package:release
```

发布前还需运行 `npm run submission:check`，检查版本、正式构建及许可携带情况。Release CI 同样执行此门禁；本地检查通过不代表已经通过官方审核。

依赖变更后运行 `npm run licenses:generate` 并审查差异。许可检查会核对依赖、复核记录与随包声明是否一致，不能代替对授权和分发条件的核查。`verify` 覆盖类型、严格核心类型、自动测试、构建及语法；运行文件由 `src/` 生成。插件 ZIP、独立词典 ZIP 和校验文件位于 `release/`，不包含用户数据。

通过 [GitHub Issues](https://github.com/lrb1019/jarvis-reader/issues) 反馈，请附上插件及 Obsidian 版本、系统、主题、复现步骤和脱敏日志；请勿公开密钥、私有书籍或整个仓库。
