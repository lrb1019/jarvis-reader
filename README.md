# Jarvis Reader

Obsidian EPUB 阅读与知识沉淀插件 · [English](./README.en.md)

当前版本：**[1.4.4](https://github.com/lrb1019/jarvis-reader/releases/tag/1.4.4)**。

在 Obsidian 中阅读 EPUB，把摘录与感想保存到 Markdown，通过双链连接已有笔记，再把值得保留的片段提炼为知识笔记。

**阅读 → 高亮 → 写笔记 → 建立关联 → 提升为知识笔记。** 离线查词、AI 翻译和词汇收藏只为这条阅读流程提供辅助。

## 定位

Jarvis Reader 的重点不是替代专业电子书阅读器，而是让阅读成为 Obsidian 知识库的输入端：原文、感想和关联先保存在每本书的一份 Markdown 读书笔记中，再由你主动把有价值的片段提升为独立知识笔记。

英语辅助与阅读统计服务于阅读，不是独立的背单词或复习产品。插件不为每条高亮创建文件，也不会自动把摘录提升为知识笔记。

## 当前功能

| 功能 | 操作与行为 |
| --- | --- |
| 图书库 | 网格／列表浏览、搜索、状态筛选与排序；单击选中、双击打开，恢复上次阅读位置 |
| 书籍管理 | 封面下显示百分比与三个点菜单；编辑状态、评分、日期、标签，更换／恢复封面，补录时长，删除书籍 |
| 阅读设置 | 字号、行距、字符／词间距、首行缩进、正文宽度、1／2栏分页和单栏滚动；侧栏收放后重新适配尺寸 |
| 阅读侧栏 | 目录、书签、笔记／高亮；笔记搜索与展开式筛选，点击定位原文 |
| 高亮与笔记 | 选文后右键操作；同一摘录可追加多条笔记、关联已有文件 |
| 知识笔记 | 主动从阅读片段生成，包含原文、全部笔记及来源；重复提升优先打开已有笔记 |
| 英语辅助 | 内置 ECDICT 离线释义；主动 AI 翻译；手动收藏单词和短语，无独立单词本或复习系统 |
| 阅读统计 | 自动阅读计时、手动补录、周／月／年图表与阅读排行 |

没有独立书籍详情页。选中文本本身不会自动弹出操作菜单或翻译结果。普通 Markdown 文件不启用全局查词或词条标记。

## 安装与更新

### BRAT

在 Obsidian 的 BRAT 插件中添加 `lrb1019/jarvis-reader`，安装正式 Release。已有安装通过 BRAT 检查更新；日常仓库只接收正式发布，不直接部署开发文件。

### 手动安装

1. 从 [GitHub Releases](https://github.com/lrb1019/jarvis-reader/releases) 下载完整 `jarvis-reader-版本号.zip`。
2. 解压到仓库的 `.obsidian/plugins/jarvis-reader/`，运行文件直接位于该目录，不要多嵌套一层。
3. 在 Obsidian「设置 → 第三方插件」中启用 Jarvis Reader。

完整目录必须包含：

```text
main.js
manifest.json
styles.css
dictionaries/ecdict/
THIRD_PARTY_NOTICES.md
```

只下载三个运行文件不会带上离线词典。更新时替换发布文件，保留已有 `data.json`、索引、缓存与备份。升级前请备份插件数据和笔记，并阅读目标版本的 [Release 说明](https://github.com/lrb1019/jarvis-reader/releases)，尤其是从旧版升级时的数据迁移与功能退出事项。克隆 `main` 得到的是开发源码，可能包含尚未发布的改动。

## 从阅读到知识

1. 在设置中指定书籍文件夹，放入 EPUB；留空时书架扫描整个仓库。
2. 单击选中书籍，双击打开。阅读器标题栏右上角常驻书签、读书笔记和阅读设置入口，章节名与工具同一行；左侧目录、书签和笔记图标切换内容。
3. 选中原文后右键，选择高亮或笔记。每本书使用一份 Markdown 读书笔记，不为每条高亮生成文件。
4. 点击有笔记的标记打开笔记卡；查看完整原文、追加或编辑感想，用 `[[笔记名]]` 连接已有内容。单条笔记的更多菜单提供编辑与删除。
5. 对有价值的片段主动创建知识笔记；从来源链接返回读书笔记或 EPUB 原文。改名、移动后仍依靠稳定来源关联；删除来源文件或移出仓库不能视为普通改名。

新建笔记使用简洁 Markdown 模板。读书笔记保留摘录、全部感想和关联，时间及返回原文链接靠右显示；知识笔记以感想为先，再保留原文与来源双链。来源文件改名时链接可随 Obsidian 更新。自定义初始模板和已有笔记不会批量替换。笔记卡保留标题、列表、引用与代码的层次和缩进。

侧栏书签与高亮片段在右键菜单中删除。删除书籍默认保留 Markdown 读书笔记及独立知识笔记。

### 文件夹设置

四个目录独立配置，使用仓库相对路径：

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 书籍文件夹 | 留空 | 筛选书架中的 EPUB |
| 读书笔记 | `Reading Notes` | 每本书的 Markdown 摘录与笔记 |
| 知识笔记 | `Knowledge Notes` | 用户主动提炼出的独立笔记 |
| 封面 | `Cover` | 上传的自定义封面 |

保存目录设置时创建缺失目录；后三个目录不会被强制绑定为书籍目录的子文件夹。可以自行设为 `books/Reading Notes` 等路径。设置目录不会自动搬迁已有文件。

### 查词与翻译

在 EPUB 内选择英文单词，再从右键菜单查询内置 ECDICT。词典按26个字母分片加载，无需导入或联网；许可见 [第三方说明](./THIRD_PARTY_NOTICES.md)。短语、句子与离线未命中内容可主动调用配置的 AI 接口。

查询不等于收藏。只有主动保存才创建词条，长句可翻译但不新增词条。AI 失败不应阻塞高亮、笔记和离线释义。

### 补录阅读时长

用于补充未被插件自动计时的阅读，例如在其他设备上阅读。选择日期并填写分钟数后，时长累加到该日期并参与统计；不是覆盖整本书的自动计时。

## 数据与隐私

数据默认保存在当前 Obsidian 仓库：

| 位置 | 内容 |
| --- | --- |
| `data.json` | 设置、阅读位置、进度、书签及阅读计时 |
| 书籍 Markdown 笔记 | 摘录正文、完整感想与关联链接的权威内容 |
| `index/highlights.json` | 高亮身份、颜色、章节与 EPUB CFI 定位 |
| `index/word-assets.json` | 收藏词条、释义与来源 |
| `cache/covers/` | 可重新生成的封面缓存 |
| `logs/index-changes.jsonl` | 索引审计记录 |

独立知识笔记属于用户 Markdown 内容。缓存和索引摘要不替代正文；仅凭 Markdown 无法重建丢失的 EPUB CFI 定位。请备份笔记以及插件数据，避免公开上传这些文件。

离线查词无需外部请求。AI 翻译只在主动触发时发送选文及必要上下文到配置的服务，不发送整本书或整个章节。

## 兼容性与验证边界

阅读区域与工具界面跟随 Obsidian 主题。完整第三方主题矩阵、真实同步服务传输、进程崩溃及各版本 BRAT 新装／升级并非全部经过实机验证；具体证据与未验证项见 [改动日志](./项目管理/03%20改动日志.md)。

插件包含对 Claudian 底部禅模式的布局适配：工作区有 EPUB 打开时，底部输入框作为浮层，不再随“已选内容”标签增高而预留更多正文空间；关闭全部 EPUB 后恢复 Claudian 原布局。浮层可能遮挡底部正文，也会影响同一工作区内的其他分栏。该适配依赖 Claudian 的内部 CSS 类名，尚未完成实机验收。Claudian 不是核心阅读功能的必要依赖。

## 开发与历史

源码位于 `src/`，`main.js` 由构建生成，不手工修改。使用 Node.js 24：

```sh
npm ci
npm run verify
npm run package:release
```

`verify` 包括普通／严格核心类型检查、测试、生产构建与产物语法检查。发布包包含词典与许可，不包含用户数据。
