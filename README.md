# Jarvis Reader

当前版本：1.4.1

中文说明 | [English](./README.en.md)

Jarvis Reader 是融入 Obsidian 的 EPUB 阅读插件：阅读原文、保存高亮和感想到 Markdown，通过双链连接已有笔记，并从笔记返回书中原文。离线释义、AI 翻译和单词短语收藏为阅读提供辅助。

插件内置 ECDICT 离线词典。选中英文单词后可直接查询，无需额外导入词典或配置本地路径。词典数据按 26 个字母分片加载，来源与许可见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

## 功能亮点

- **图书库界面**：支持网格和列表两种浏览方式。
- **Frontmatter 状态同步**：图书的在读、已读、未读、评分、标签等信息可与对应 Markdown 读书笔记对齐。
- **沉浸式 EPUB 阅读**：集中调整字号、行距、字符／词间距、首行缩进和正文宽度，支持分页 1／2 栏与单栏滚动、目录导航和阅读位置恢复。
- **划线与笔记**：支持普通高亮、写笔记、追加笔记、打开对应 Markdown 块、侧栏筛选和跳回原文位置。
- **阅读书签**：可在阅读器中保存当前位置，并从阅读侧栏精确跳回 EPUB CFI 位置。
- **离线查词与 AI 翻译**：单词优先走内置 ECDICT；短语、句子或未命中内容可由用户显式触发 AI 翻译。
- **轻量词汇收藏**：只主动保存单词和短语，保留释义、来源和再次查询；不提供复习系统或独立单词本。
- **Markdown 单词识别**：已保存单词可在普通 Markdown 笔记当前可视区域内被识别并显示词卡。
- **TypeScript 源码工程**：源码位于 `src/`，根目录 `main.js` 由 esbuild 构建生成。

## 安装

1. 从 [GitHub Releases](https://github.com/lrb1019/jarvis-reader/releases) 下载正式版本安装包。克隆 `main` 获得的是未发布开发版。
2. 将整个目录复制到你的 Obsidian 仓库：

```text
.obsidian/plugins/jarvis-reader
```

3. 确认目录中至少包含：

```text
main.js
manifest.json
styles.css
dictionaries/ecdict/
THIRD_PARTY_NOTICES.md
```

4. 打开 Obsidian。
5. 进入 `设置 -> 第三方插件`。
6. 如有需要，重新加载插件列表。
7. 启用 `Jarvis Reader`。

## 使用

- 点击 Obsidian 左侧栏中的 Jarvis Reader 图标打开图书库。
- 从图书库中打开 EPUB。
- 阅读时选中文本，再右键打开菜单，可选择高亮、笔记、复制、离线释义或 AI 翻译。
- 普通高亮只保存原文；笔记会同时保存原文和你的内容到对应 Markdown 读书笔记。
- 点击有笔记的划线可直接打开只读笔记窗口。
- 笔记窗口右上角的 `pencil` 打开对应 Markdown 块，`file-pen-line` 追加笔记，`x` 关闭窗口。
- 有感想的划线可通过笔记窗口中的创建知识笔记按钮生成独立 Markdown 笔记；新笔记包含原文、全部个人笔记、来源块链接和返回 EPUB 原文链接，目录可在插件设置中调整。
- 选中英文单词后，在右键菜单主动查询内置 ECDICT 释义；仅选中不会自动弹出结果。
- 选中短语或句子后点击 AI 翻译，可主动调用配置的接口。
- 查询不会自动收藏；只在主动保存时记录单词或短语。长句不保存为词条。
- 在笔记中输入 `[[笔记名]]`，可把阅读笔记连接到你的知识库。
- 可在插件设置中配置读书笔记路径、模板、AI 翻译接口和发音选项。

## 数据与隐私

Jarvis Reader 默认将数据存储在你的本地 Obsidian 仓库中。

主要数据位置：

- `data.json`：插件设置、阅读位置、阅读进度和书签等轻量数据。
- `cache/covers/`：按书籍独立保存的本地封面缓存。
- `index/word-assets.json`：已收藏单词和短语的主数据。
- `index/highlights.json`：高亮身份、颜色与 EPUB CFI 定位元数据的权威索引。
- `logs/index-changes.jsonl`：索引变更日志。
- 图书对应的 Markdown 笔记：承载摘录原文、完整感想与关联链接的权威内容。

这些本地数据不应提交到公开 GitHub 仓库。仓库中的 `.gitignore` 已排除常见本地数据文件。

外部 AI 翻译只会在用户显式触发时调用。内置 ECDICT 查词不需要网络连接。

## 开发

当前仓库是 TypeScript 源码工程。

常用命令：

```powershell
npm install
npm run verify
```

`npm run verify` 会依次执行：

1. TypeScript 普通与严格核心类型检查。
2. Node 测试。
3. esbuild 生产构建。
4. `node --check main.js`。

开发规则：

- 功能改动应修改 `src/`。
- 不要手改 `main.js`，它应始终由构建流程生成。
- 发布或提交前执行 `npm run verify`。
