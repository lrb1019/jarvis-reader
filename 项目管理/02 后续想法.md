# 后续想法

本文件只收录尚未完成或需要继续验证的事项。优先级依据数据风险、主工作流影响和实际使用频率确定。

2026-09-26 的 P0 数据安全验收已在 `Obsidian-test` 完成，范围和未模拟情形见 `03 改动日志.md`。下列事项仍需后续处理。

## P1：减少长期维护风险

### 当前优先：阅读笔记主流程的剩余边界

配套 [功能取舍与精简清单](../docs/plans/2026-09-28%20功能取舍与精简清单.md) 已单独列出退出与弱化范围。智能指令、复习系统、独立词条管理界面及长句词条模型的源码退出、自动验证和本轮 Obsidian 实机回归均已完成。旧智能指令配置首次加载时备份后删除。根据用户授权，复习迁移不保留旧复习字段或迁移备份；当前 vault 的 2 条历史长句词条已通过原子 sidecar 写入删除。英语辅助保留离线查词、主动 API 翻译和手动保存单词短语，独立单词本、词条列表与词条侧边栏已移除；详细阅读统计先保持现状，后续再讨论。仅清理已授权的学习记录、掌握状态和长句词条，保留其余用户数据。

之后按 [阅读笔记融入 Obsidian 实施方案](../docs/plans/2026-09-28%20阅读笔记融入%20Obsidian%20实施方案.md) 处理未完成的来源识别、书籍移动和格式兼容问题，再通过样例决定格式减负。Markdown 返回原文与知识笔记双向访问已实现，用户已实测新建、两条返回链接及改名后再次提升。引用读书总笔记直接使用 Obsidian 块双链，引用独立知识笔记直接使用文件双链；原计划“复制为引用／复制原文链接”取消。阅读参数范围一致性修正排在主流程问题之后，作为独立任务。

方案于 2026-09-28 编写；智能指令、复习、词条界面与长句词条退出均已完成本轮实机验收。下列已有事项保留，来源健康度和路径身份事项并入对应阶段核对，避免重复实现。期间不扩展智能指令和记忆系统。主方案不删除已有数据；已单独按用户授权清理复习记录、掌握状态、复习专属配置及当前 vault 的历史长句词条，保留词义、来源、单词短语收藏和阅读统计。

### 1. 统一阅读片段展示组件

把侧边栏摘要卡、正文完整卡和详情页完整卡建立在同一标准数据对象上。允许外观不同，不允许内容解释不同。

### 2. 增加解析诊断

当 Markdown 片段解析失败时，记录：

- 书籍标识
- 笔记路径
- 块 ID
- 失败阶段
- 是否已回退

日志不得记录完整隐私内容。

### 3. 增加备份恢复入口

在设置页提供只读检查和明确恢复动作，避免用户直接处理 `.bak`、迁移备份和冲突文件。

### 4. 检查知识笔记来源健康度

识别以下问题：

- 来源块被删除
- 来源笔记被移动
- 同一来源出现多个知识笔记
- 来源元数据缺失

默认只报告，不自动合并或删除。

### 5. 统一书籍路径身份

书籍位于指定目录时，以稳定路径和书籍标识为准，避免引入“不同目录同名书”的无效复杂度。

### 6. 完整实机回归

按用户闭环而不是零散按钮进行回归：

- EPUB：打开、目录、翻页、滚动、单双页、字号、行距和位置恢复
- 标注：纯划线、写笔记、追加、编辑、删除、侧边栏同步和跳回原文
- 词汇：离线查词、AI 翻译、收藏、悬浮卡、删除和重开恢复；确认复习、掌握和 SM-2 入口不再出现
- 图书库：搜索、筛选、排序、封面、状态、书签和阅读器联动
- 知识笔记：提升、重命名、再次打开、来源链接和独立删除

### 7. 继续观察跳转原文

在更多 EPUB、跨章节、连续切书和书籍未打开的状态下验证 CFI 跳转，不以单本测试通过代替整体结论。

### 8. 大型组件继续拆分

只在真实改动需要时逐步拆分阅读器、图书库和样式文件。拆分目标是明确职责，不为了文件变小而制造更多跳转层。

## P2：体验优化

### 阅读体验与排版改进方向

用户已同意形成后续计划，详见 [阅读体验与排版改进计划](../docs/plans/2026-09-28%20阅读体验与排版改进计划.md)。阅读器内固定设置入口、集中面板和可选快捷按钮另见 [阅读器侧栏与阅读设置实施计划](../docs/plans/2026-09-29%20阅读器侧栏与阅读设置实施计划.md)。2026-09-30 R0 参数范围修正、124 项自动检查及中英文普通正文实测已完成，特殊排版等覆盖待补；B–C 固定入口、已有参数面板及快捷入口选择已实现并完成主要验收（127 项自动测试通过），完整验收矩阵见实施计划第 8 节。正文宽度与分屏按 R1 继续，R2 字体与段落、R3 操作隔离、R4 单书设置后续按样例决定。正文总宽度与 1／2 栏已实现（130 项检查通过）；首行缩进“遵循原书／两字／不缩进”已实现并通过 136 项检查及中文正文、特殊排版测试页面与插件重载验收，默认遵循原书，只处理普通正文。下一项先诊断长书名裁切与页数刷新，字体选择等尚未实施。不复制 Readest 全部设置，不替代当前核心笔记与精简任务。

### 1. 英语辅助收敛为轻量功能

- 保留发音、核心释义和来源上下文；保留手动保存单词短语和再遇点击查看，移除独立单词本、词条列表和词条侧边栏。
- 记忆复习及其学习记录、掌握状态的源码退出与自动验证已完成；不保留启用开关，仍待实际 vault 升级迁移验收。

### 2. AI 翻译状态优化

- 清楚区分离线词典结果和 AI 翻译结果。
- 请求失败时保留离线结果。
- 不因 AI 服务不可用影响划线和笔记。

### 3. 移动端与窄屏检查

重点检查：

- 侧边栏宽度
- 弹窗边界
- 顶部操作图标
- 长单词和多标签
- 详情页封面与信息布局

### 4. 阅读统计减负

阅读进度和位置恢复明确保留；累计时长、详细图表及历史阅读记录先保持现状，后续再讨论，不新增统计功能。

移除复习时清理复习次数与复习时长，保持阅读统计现状；核对二者没有混删。

### 5. 第三方智能指令退出

源码退出与自动验证已完成：选文、笔记窗口和设置入口、专用适配及对应代码已删除；旧 `smartCommands` 配置将在首次加载时备份后删除。保留 Markdown AI 内容、关联和外部 Skill 文件，不卸载 Claudian，不影响高亮、笔记、翻译和保存。尚待 Obsidian 实机回归。

## 暂不实施

### 第三方离线词典导入（2026-09-28 暂缓）

用户明确此项非核心功能，仅保留思路，不修改现有查词实现。当前继续使用内置 ECDICT。未来有实际需要时，再评估用户导入 MDict 或 StarDict、选择默认词典，以及保存释义后不依赖原词典文件的方式；格式支持与范围届时再决定。此项不进入当前开发顺序。

### 其他暂不实施事项

- 每条划线独立文件
- 云端账号系统
- 自建同步服务
- 复杂间隔重复算法
- 3D 书架或封面流
- 自动删除孤立 Markdown
- 为无法复现的单条历史数据增加永久兼容层

## 评估新想法的标准

任何新功能都先回答：

1. 是否直接增强“阅读到知识笔记”的主流程？
2. 是否会增加数据损坏风险？
3. 是否会让 13 英寸屏幕更拥挤？
4. 是否可由现有 Obsidian 能力完成？
5. 删除这个功能后，核心价值是否仍然成立？

若只提升视觉新鲜感而不改善主流程，默认不做。
