## 三、必须先理解的架构

### `BookNoteService`

负责读取和操作每本书的 Markdown 读书笔记。新功能不得绕过它直接在界面层解析文本。

### `HighlightService`

负责高亮元数据及其查询。

### `HighlightTransactionService`

负责高亮相关写入事务、回滚和启动恢复。

### `BookStateService`

负责阅读位置和书籍运行状态。

### `KnowledgeNoteService`

负责将阅读片段提升为知识笔记，并通过来源身份查找已有文件。

### `CoverCacheService`

负责本地封面缓存。书架和详情页应优先使用缓存，不应反复从 EPUB 慢速读取。

### 设置保存队列

所有设置保存必须串行化，避免多个界面同时保存时相互覆盖。

智能指令现支持两种来源：

- 模板：继续发送设置中保存的固定指令，兼容原有配置。
- Skill 文件：保存 Vault 相对目录，调用前验证其中的 `SKILL.md`，只把相对路径和当次阅读任务发送给 Claudian，由 Agent 使用文件读取工具加载最新内容；验证失败时停止调用。

设置页的智能指令列表只显示名称和描述，不在列表中重复展示 Skill 路径或出现范围；完整配置仍可从编辑窗口查看。

Skill 文件模式的设置、列表展示和路径引用消息已经实机确认；发送内容压缩为“读取并遵循：相对路径”加阅读内容，不含 Skill 正文、任务边界标记或重复书名。选文后直接在 Claudian 侧栏提问已由用户的 `bylrb` 截图展示；截图本身不能证明选文上下文由哪一个插件注入。智能指令则由 Jarvis Reader 的选文菜单或划线笔记窗口明确触发，后者取已保存的笔记。
