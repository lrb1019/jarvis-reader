## 2026-07-28 知识笔记前台打开修复

### 根因与修复

- “提升为知识笔记”已经成功创建或找到知识笔记，但新建标签页后没有显式激活并聚焦；阅读器弹窗继续停留在前台，用户看到的表现是点击无反应。
- 新增统一的工作区文件导航函数：文件打开成功后显式激活并聚焦目标标签页；打开失败时不切换活动标签页。

### 验证

- `npm run verify` 通过：普通类型检查、严格类型检查、92 项测试、生产构建和 `main.js` 语法检查全部通过。
- 在实际使用的 bylrb vault 中更新运行文件并重新加载插件后完成实机验收：点击“提升为知识笔记”会立即前台打开已有知识笔记并显示成功提示，未生成重复文件。
- 固化非发布验收流程：新增 `npm run deploy:local`，完整验证后仅向本机配置的实际 vault 部署 `main.js`；验收通过后用普通提交同步云端，版本标签保留给正式发布。
- 明确区分两类交付：小改动验收后只用普通提交同步云端；累计改动只有在用户明确决定发布后才升级版本、创建标签和 GitHub Release。
