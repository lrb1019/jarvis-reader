## 2026-07-31 笔记编辑方向键与翻页隔离

### 根因与修复

- EPUB 阅读器在整个文档上监听左右方向键的 `keyup` 事件进行翻页。
- 当前笔记窗口使用的 CodeMirror 编辑器未阻止左右方向键事件继续冒泡，因此光标移动和 EPUB 翻页会同时发生；旧备用输入框已有隔离，不是 EPUB 内容问题。
- 在 CodeMirror 编辑器及备用输入框内同时拦截左右方向键的 `keydown` 和 `keyup` 冒泡，但不阻止编辑器默认行为；输入时左右键只移动光标，编辑器外的翻页行为保持不变。

### 验证

- `npm run verify` 通过普通与严格类型检查、102 项测试、生产构建和 `main.js` 语法检查。
- 新增测试确认只识别 EPUB 使用的左右方向键，不影响上下方向键和其他编辑按键。
- bylrb 实机确认：笔记输入框内左右方向键只移动光标，不再触发 EPUB 翻页。

## 2026-07-29 临时翻译卡自由拖拽

### 根因与修复

- 临时翻译卡复用了笔记窗口的拖拽边界，并按约 420px 的笔记窗口高度计算底部位置；翻译卡实际更矮，因此视觉上尚未到底时就被提前截停。
- 为临时翻译卡建立独立位置状态和无笔记窗口边界的移动计算，使其拖拽方式与已保存词卡一致；笔记窗口原有边界不变。
- 每次打开新的临时翻译卡时恢复默认位置，防止上一次拖出可视区的位置影响下一次查询；双击标题仍可恢复默认位置。

### 验证

- `npm run verify` 通过普通与严格类型检查、101 项测试、生产构建和 `main.js` 语法检查。
- 新增测试确认向下移动不再受到笔记窗口高度边界截断；bylrb 实机确认临时翻译卡可自由拖拽。

## 2026-07-28 读书互动 Skill 文件模式

### 根因与修复

- 原智能指令只保存并发送一段固定模板，不能从知识库中的独立 Skill 文件加载最新指令。
- 新增“Skill 文件”指令来源：设置中保存知识库相对目录，调用前验证目录内的 `SKILL.md` 存在且非空，再把文件相对路径和当前阅读任务发送给 Claudian，由 Agent 使用文件读取工具加载最新 Skill；不再把 Skill 全文展开到对话框。
- 路径引用消息压缩为“读取并遵循：相对路径”加阅读内容，移除 `TASK START/END`、长说明和重复书名。
- 保留原有“指令模板”模式；旧配置未声明来源时仍按模板处理。
- 保存和调用时拒绝绝对路径、知识库外路径、非 `SKILL.md` 文件；文件缺失、为空或读取失败时停止发送并显示原因。
- 智能指令列表的副标题只显示用户填写的描述；Skill 路径、指令来源和出现范围保留在编辑窗口中。

### 验证

- `npm run verify` 通过普通与严格类型检查、102 项测试、生产构建和 `main.js` 语法检查。
- 新增测试覆盖目录补全、路径越界、旧模板兼容、只发送文件路径而不展开正文、默认阅读上下文，以及文件缺失、空文件和读取失败。
- bylrb 实机确认设置列表只显示描述；Claudian 按路径读取 Skill 的新发送方式待用户验收。

## 2026-07-28 图书详情标签交互恢复
