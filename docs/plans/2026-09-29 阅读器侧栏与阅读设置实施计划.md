本计划落实 [阅读体验与排版改进计划](2026-09-28%20阅读体验与排版改进计划.md) 的设置入口与常用排版控制。该计划的 R0–R4 仍负责具体排版能力；本文负责入口、交互、状态归属和分阶段交付。参考 Readest 的阅读页内集中设置、即时预览和重置方式，不复制其完整独立 App 设置体系。

## 1. 任务定义

| 项目 | 内容 |
| --- | --- |
| 用户场景 | 阅读中随时打开完整阅读设置；把书签、打开本书笔记等常用操作放在左侧；按个人习惯勾选其余快捷入口。 |
| 当前行为 | 左侧整组按钮仅悬停或聚焦时显示；按钮固定且没有总设置入口。字号、行距、单双页和滚动方式分散在左侧与 Obsidian 插件设置中。 |
| 证据 | `src/reader/ReaderSideControls.tsx` 固定渲染 8 个按钮；`styles.css` 通过 `opacity: 0` 隐藏整组；`src/EpubView.ts` 负责现有参数保存。设置页字号范围为 0.5–3.0、行距为 1.0–3.0，而 `src/theme.ts` 的实际范围分别为 0.6–2.0、1.1–2.4。 |
| 目标 | 同组左侧快捷栏末尾固定「阅读设置」按钮，整组靠近左侧才显示；点击后在阅读器内打开完整阅读设置面板。其余快捷入口可勾选，操作与面板共享同一状态。 |
| 完成条件 | 固定入口始终可用；面板与快捷入口双向同步；设置保存、关书重开后保持；窄分屏下可操作且不挡正文；原文定位和笔记工作流无回归。 |
| 排除 | 书架重做、独立主题系统、第三方字体导入、词典／AI／存储配置迁入阅读面板、每书独立设置的首轮实现。 |
| 数据 | 阅读偏好继续由现有 `data.json`／设置保存队列负责；阅读位置、书签、Markdown 和高亮索引不因界面调整而迁移。 |

这是一个界面与设置一致性任务，没有已确认的运行时故障根因。实施前需以当前 Obsidian 界面确认固定按钮会否遮挡正文、设置值与正文是否同步；若发现定位或保存故障，先单独诊断。

## 2. 界面结构与可见性

阅读器左侧保留一组悬停快捷按钮，设置齿轮是其中最后一项，不单独常显，也不进入可取消勾选清单。平时整组隐藏，鼠标靠近阅读区域左边缘时一起显示，移开后隐藏；面板打开及键盘可见焦点期间保留显示。其他按钮按用户勾选与固定顺序展示，不做拖拽排序。默认选择「添加书签」「打开本书笔记」；未勾选只隐藏入口，不改变书籍或能力。

建议布局：

```text
阅读器左侧                   阅读设置面板（从左侧按钮打开）
┌────────┐                  ┌──────────────────────────────┐
│ 书签   │                  │ 阅读设置                 关闭 │
│ 笔记   │  可选快捷按钮    │ 字号、行距、页面模式、正文宽度 │
│ …      │                  │ 恢复阅读默认值               │
│        │                  │ 左侧快捷入口：复选框列表     │
│ 设置 ⚙ │  同组固定末项      └──────────────────────────────┘
└────────┘
```

面板属于**阅读器内的阅读设置**，不是第二份完整插件设置。笔记目录、翻译 API、词卡、高亮颜色等继续留在 Obsidian 的 Jarvis Reader 插件设置页；需要时可从阅读面板提供「打开插件设置」普通链接，但首轮不重复渲染这些配置。原插件设置页中已有的阅读参数与面板使用同一字段，修改任一处后，另一处重新显示时必须读到最新值。

面板不覆盖整页：大窗口从左侧展开；窄分屏改为受容器限制的浮层或抽屉，内部可滚动、正文不出现横向溢出。开关面板不触发 EPUB 重新加载、不改阅读 CFI。点击外部或按 Escape 关闭；面板内点击与滑动不得触发翻页、选文菜单或正文卡片；关闭后焦点回到设置按钮。按钮有文字提示、`aria-label`、可见焦点与当前状态提示。设置按钮为 `aria-expanded`，面板与按钮建立关联。

设置按钮始终可见不等于整条工具栏必须长期占据正文宽度。具体占位应在 13 英寸窗口和窄分屏实测：优先让按钮停在阅读容器边缘，必要时给正文留下相应安全间距，不用透明遮罩盖住正文点击区域。工具栏高度不够时快捷项可收起或滚动，固定设置按钮不能被挤出视口。

## 3. 首轮设置清单与行为

| 设置／动作 | 阅读面板 | 左侧快捷入口 | 当前状态与实施方式 |
| --- | --- | --- | --- |
| 添加书签 | 不作为排版参数；保留操作说明即可 | 默认显示、可隐藏 | 沿用当前 CFI 与书签服务；缺少有效位置时禁用并说明。 |
| 打开本书笔记 | 不作为排版参数 | 默认显示、可隐藏 | 沿用当前打开／创建书笔记动作。 |
| 字号（现名「缩放」） | 当前值、范围、调整和恢复默认 | 可选 `− / +` | 统一控件与运行时边界；面板和快捷按钮都调用既有视图入口。显示百分比或倍率，术语全界面一致。 |
| 行距 | 当前值、范围、调整和恢复默认 | 可选 `− / +` | 同上；步进与界面显示一致。 |
| 阅读方式 | 「分页」「滚动」单选 | 可选切换 | 滚动目前只在单页有效；双页时禁用滚动并解释原因，不提供看似生效的无效按钮。 |
| 页面布局 | 「单页」「双页」单选 | 可选切换 | 保持当前状态转换规则，清楚显示有效模式。 |
| 正文最大宽度 | D 批加入数值或有限档位，允许恢复默认 | 暂不加入 | 先核对 EPUB 容器、分页引擎与分屏，不直接以 CSS 限制 `body`。详见原计划 R1。 |
| 左侧快捷入口 | 复选框，固定顺序，预览立即更新 | 本身即展示结果 | 单独存储可见项 ID；设置按钮不能取消勾选。 |

首轮不把段距、字体来源、两端对齐、断词、四边距、书籍专属设置一起塞进面板。原计划 R1/R2/R4 完成并经过 EPUB 样例验收后，再把经过验证的能力加入相应分组。颜色与字体默认继续跟随 Obsidian。

「恢复阅读默认值」只重置阅读排版字段（字号、行距、分页与单双页；正文宽度上线后再纳入），不重置快捷入口偏好、阅读进度、书签、划线、笔记或插件的翻译与存储配置。首轮全书共享现有阅读偏好，不出现「仅本书」按钮；单书覆盖待原计划 R4 再实施，避免界面暗示目前不存在的能力。

## 4. 状态与实现边界

1. **单一权威**：`JarvisReaderSettings` 的现有阅读字段继续作为当前全局阅读偏好。快捷项新增一个最小字段，例如稳定动作 ID 列表，默认书签和本书笔记；加载旧配置时补默认值，无需扫描或改写真实书籍与 Markdown。未知 ID 忽略，不渲染失效按钮。
2. **单一路径**：面板滑块、左侧按钮和 Obsidian 插件设置页最终调用同一套设置更新／规范化逻辑，通过现有保存队列持久化。不要从 React 组件直接写 `data.json`，也不要为面板维护独立持久副本。
3. **即时反馈与失败**：用户调整后先让当前阅读页反映有效值；保存失败须显示可理解的提示，并保留可重试状态，不把失败写成已保存。连续拖动滑块应减少昂贵的重新分页／磁盘写入；明确区分预览值和最终提交值。
4. **范围一致**：把字号与行距限制定义在一个共享规则中，设置页、面板、快捷按钮和 EPUB 运行时复用；旧值读入时按规则显示，不因打开面板就静默重写用户配置。实际极值要用中文、英文、长词和窄屏 EPUB 验收。
5. **阅读位置**：打开／关闭面板和勾选快捷项不更改当前位置。改变字号、行距、布局时允许重新分页，但应保留当前 CFI 锚点；过期异步恢复不得覆盖用户随后主动进行的跳转。若现有 `onLoadFile` 路径会重载整本书，先确认它不会把笔记来源跳转复位到旧书签。
6. **分工**：`ReaderSideControls` 负责按钮显示与事件；新面板只负责展示和提交意图；`EpubReader` 维护面板开闭这类临时 UI 状态；`EpubView`／现有服务负责修改设置和保存；`settings.ts` 继续负责插件设置页。必要时抽出共享的纯设置规则，不复制一套 clamp 或持久化流程。

入口文件预计涉及 `src/reader/ReaderSideControls.tsx`、`src/EpubReader.tsx`、`src/EpubView.ts`、`src/settings.ts`、`src/types.ts`、`src/theme.ts`、`styles.css` 及相关测试。`main.js` 只通过构建生成，不手改。具体文件清单在每一批开始前以当前源码复核。

## 5. 分批实施

### A. 阅读参数一致性（对应原计划 R0）

- 复现并记录现有滑块的无效区间、当前书重开后的值和极值排版。
- 合并字号／行距的边界与步进规则；使设置页显示值等于 EPUB 实际使用值。
- 验收旧配置、非法值、保存失败、重启和主题切换。此批不改左侧栏布局。

### B. 固定入口与阅读设置面板

- 将左侧齿轮按钮放入同组末尾，整组悬停显示，设置项不可取消勾选；其余按钮暂保留现有功能。
- 创建阅读器内面板，先接入已有字号、行距、单双页、分页／滚动与恢复默认。
- 处理面板的打开、关闭、焦点、窄屏、外部点击和事件隔离；不新增设置文件。
- 验收从原文返回、连续翻页、选文、书签和笔记入口。B 完成时用户已能只靠固定按钮找到全部现有阅读控制。

### C. 可选快捷入口

- 在面板中加入固定顺序的快捷项复选框，默认为书签和本书笔记；把字号、行距、阅读方式、单双页列为可选项。
- 仅保存可见性；旧配置使用默认值，空列表仍保留设置按钮。
- 同书、切书、关闭重开和重新加载插件后核对偏好；确认快捷操作与面板数值双向同步。

### D. 正文宽度与分屏（对应原计划 R1）

- 在排版引擎中验证正文宽度、单双页栏宽与容器 resize 的关系，再增加面板中的宽度控制。
- 窄分屏自动缩小**有效**宽度，用户偏好不随窗口变化被改写；展开窗口后恢复。
- 保留 CFI 与高亮位置，验收长词、图像、表格、打开笔记侧栏和连续拖动分隔条。D 不阻塞 A–C 的交付。

### E. 以后按实际样例扩展

字体来源、段距和原书样式按原计划 R2；点击翻页与选文冲突按 R3；单书覆盖按 R4。每项都先取得具体 EPUB 样例和当前行为记录，再决定是否进入面板。Readest 的完整字体管理、主题编辑和自定义 CSS 不进入本计划。
