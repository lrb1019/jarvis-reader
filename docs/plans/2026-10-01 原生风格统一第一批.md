# 原生风格统一第一批

Task：收敛界面字号、统计入口及评分控件。
Task type：展示与可访问性。
User scenario：在主题下使用书架、统计、阅读设置与笔记卡。
Current behavior：局部界面固定字号；统计返回采用文字胶囊；评分 span 仅支持点击。
Reproduction：源码审查确认，资料窗口实机显示评分无可访问控件名称。
Root-cause evidence：LibraryApp 的评分 span／内联字号，EpubReader 的内联字号，styles.css 阅读设置和返回按钮规则。
Target behavior：界面字号跟随主题；返回使用原生箭头；星级为可聚焦、具备名称和选中状态的按钮。
Completion criteria：构建检查通过；统计返回和资料窗口截图正常；评分 Tab 聚焦与 Escape 关闭通过。
Scope：阅读设置、资料／补录窗口、书架列表、笔记卡辅助文字、统计返回和入口。
Explicitly excluded：正文阅读字号、数据格式、统计计算、卡片定位、弹窗焦点限制、全量图标替换、结构清理。
Affected data and files：无新增数据写入；src/library/LibraryApp.tsx、src/EpubReader.tsx、styles.css；main.js 由构建生成。
Automated verification：npm run verify 168项测试、类型检查、生产构建、main.js语法通过，日志 /tmp/jr-native-style-verify.log；末次仅修正评分颜色，diff检查通过。
Obsidian verification：仅 Obsidian-test，重载最终样式；统计返回箭头截图、返回书架、原生管理菜单、资料窗口截图、1–5星可访问名称、Tab聚焦1星及Escape关闭通过。未修改真实评分或资料。
Failure handling：沿用原保存服务与错误提示。
Rollback：按本批 diff 恢复来源并重新构建，不覆盖先前统计改动。
Documents to update：改动日志、接续说明、审查记录。

## 结果与限制

- 界面固定 11/12/13px 等改为 font-ui-small／smaller，标题采用 medium；阅读设置圆角与阴影采用主题变量，保持原尺寸和布局。
- 统计返回为28px箭头按钮，详细统计入口使用原生图标、去掉重复文字提示及无效内联 !important。
- 评分采用标准按钮、名称和 aria-pressed；未选中为主题弱化文字色，已选中为主题强调色。原点击保存路径保留。
- 其他主题、放大界面字号、极窄分栏、阅读设置／关联列表最终实机显示和真实评分保存未复测；完整焦点管理仍在第二批。不能称为全插件风格统一完成。
