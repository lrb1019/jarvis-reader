Task: 防止关闭／切书后旧加载结果重新激活阅读器。
Task type: 已隔离复现的生命周期修复。
User scenario: 读取书籍时关闭标签、快速切换书籍、重载布局、书籍改名移动。
Current behavior: 多处await后无失效检查，旧加载能覆盖活动视图、创建第二root，迟到主题回调可重启计时。
Reproduction: 当前EpubView方法本体＋Obsidian／DOM／React替身受控延迟读取。
Root-cause evidence: 旧方法卸载后仍createRoot/render，慢旧读取覆盖快新读取；详见实证记录。
Target behavior: 加载代次与卸载标记验证，失效后不创建root、不覆盖活动阅读器、不执行旧阅读器保存／主题回调。
Completion criteria: 先失败回归、修复后受控延迟测试与完整verify通过，测试库重开／切书／关闭验证及限制记录。
Scope: EpubView加载／卸载／改名预备失效与主题启动延迟，回归及文档。
Explicitly excluded: Q03进度策略、Q01已修复逻辑、全局生命周期框架、UI风格、真实数据删除／存储故障、提交发布。
Affected data and files: EpubView.ts、生命周期测试／替身、生成main.js；不手工改权威数据。
Automated verification: 同视图并发、等待期间卸载、位置／高亮读取延迟、清理延迟、改名准备、旧回调、主题等待、读取失败后重开。
Obsidian verification: 测试库真实加载／关闭／切书；受控延迟采用隔离替身，不人为损坏书籍。
Failure handling: 当前有效加载的读取错误继续拒绝并由宿主处理；失效的成功结果停止执行。
Rollback: /private/tmp/jr-q02-view-before.ts为本任务前快照，保留C12和Q01成果；回退后重新构建。
Documents to update: 本记录、03／04、02、整改清单、实证记录。

状态：限定修复与自动／实机受控关闭、切书验收完成。测试从当前方法语法树提取真实方法／字段，替身仅代替宿主与DOM，不复制生产方法实现。

- stopThemeSync、readBinary、getInitLocation、getBookHighlightsForReader、setActiveReader等待返回后均核对。位置与高亮读完才创建root，创建／render之间不再await。
- 保存位置／进度、toc、注册编辑／删除回调、主题启动与交互带当前加载检查。失效入口清除注册字段，防止旧null cleanup残留或误清新handler；旧主题启动在清理前、清理返回后和定时回调检查，不重新启动已失效阅读器。
- 初始10项回归旧实现1通过／9失败；修复后10项全通过，再补注册清理保护一项，最终11项全通过。包含并发加载／卸载、位置／高亮等待、停止等待、改名准备、旧回调、迟到主题与读取失败后再次打开。
- 最终npm run verify退出0：204项测试、普通／strict类型、生产构建及main.js语法通过；git diff --check通过。
