## 任务边界

- Task：准备 Jarvis Reader 社区目录申请，参照已公开的阅读插件改进必要的安装与说明。
- Task type：发布准备、兼容性修复、说明与许可核查。
- User scenario：新用户仅安装三个官方运行文件即可阅读和保存笔记；词典另行手动导入。
- Current behavior / Reproduction：生产包可检出 react.development.js；配置目录非 .obsidian 时，部分 sidecar、恢复记录与缓存仍固定写入 .obsidian；manifest 声称最低0.15.0。
- Root-cause evidence：esbuild未显式定义NODE_ENV；main、cover-cache、highlight-transaction、conflict-resolution存在固定根路径；当前源码调用较晚加入的API，例如revealLeaf（本地SDK标注1.7.2）。API标注扫描不是完整的旧版本运行证明。
- Target behavior：正式构建使用React生产版；按vault.configDir保存内部数据；如实声明验证边界；许可疑点显式阻止申请放行。
- Completion criteria：自动verify、许可分发核对、三文件干净安装、实际宿主核心流程、公开Release和官方目录审核分别有证据，不能相互替代。
- Scope：上述问题、原生设置页一致性、申请检查及文档。
- Explicitly excluded：PDF、AI聊天、云同步、换阅读引擎、批量重写笔记、日常库部署、移动端功能开发。
- Affected data and files：构建、manifest/package/versions、设置页、内部路径服务与测试。存储格式与Markdown定位字段不变。
- Automated verification：npm run verify；npm run submission:check；npm run package:release。
- Obsidian verification：Obsidian-test和临时干净库，见下文。
- Failure handling：未确认许可不冒充授权；损坏与写入失败继续使用既有事务、备份和停止写入机制。
- Rollback：本轮源码可单独回退并重新构建；未改变历史发布标签或用户笔记。升级前备份插件数据，保留词典。
- Documents to update：本记录、中英文README、改动日志与接续说明。
