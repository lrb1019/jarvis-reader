# 原生风格统一第二批

Task：资料弹窗焦点与阅读卡片边界。
Task type：交互／容器适配。
User scenario：使用键盘编辑资料或补录时长；在窄分栏、侧栏切换和长词义下查看卡片。
Current behavior：资料窗口未管理打开／关闭焦点；卡片按至少320／360px容器宽度和估算高度限位。
Reproduction：源码确认界面约束冲突；初次实机受锁屏阻断，解锁后已检查资料弹窗与窄容器卡片。
Root-cause evidence：LibraryApp自绘dialog无焦点绑定；EpubReader容器下限、词卡190／220px初始估算；CSS360px最小宽度可能大于可用宽度。
Target behavior：打开后聚焦、Tab限于窗口、关闭返回触发控件；卡片按实际容器和实测尺寸限位。
Completion criteria：自动检查通过，测试库实际键盘闭环、词卡加载、拖动／缩放、侧栏切换与窄屏均验收后才算完成。
Scope：资料／补录弹窗；已保存词卡与笔记浮动卡的边界。
Explicitly excluded：选文菜单键盘改造、全插件模态化、数据及统计算法、结构清理。
Affected data and files：新增dialog-focus.ts、reader-overlay-bounds.ts；LibraryApp、EpubReader、styles.css及生成main.js；无新增数据写入。
Automated verification：npm run verify 171项测试、类型、构建和语法通过；新增3项边界测试覆盖窄容器、长卡片和正常位置；日志/tmp/jr-native-second-verify.log。
Obsidian verification：解锁后仅重载Obsidian-test。资料窗口打开聚焦关闭按钮，Shift+Tab到标签输入、Tab回到关闭，Escape后返回书籍菜单按钮；补录从日期输入循环到保存再返回，Escape取消且未保存。临时300×400px阅读区内实测词卡与笔记卡约268×368px、边界均在容器内，长词卡内容区280px／内容653px，可滚动到底。尺寸已恢复，预览变量清除、卡片与开发者工具关闭。
Failure handling：保存服务与原错误提示不变；补录保存期间仍禁止关闭。
Rollback：仅恢复本批来源改动并重新构建，保留第一批和先前统计改动。
Documents to update：改动日志、接续说明、审查进展。

## 已实现与已验证范围

- 两个资料弹窗打开聚焦首个控件；Tab／Shift+Tab循环，焦点离开时拉回；关闭解除监听并返回仍存在的原控件。补录支持Escape取消，保存期间不取消。
- 定位去掉虚构容器宽高下限；卡片最小宽高不超过容器可用尺寸。词卡按真实宽高再次限位，容器和内容尺寸变化通过ResizeObserver重新检查；笔记窗口也跟随容器缩小，观察器关闭时释放。
- 用户已认可的卡片页边距、字号、颜色、拖动与内容滚动设计保留；本批不改正文背景。

收尾追加实机：笔记拖动、手动缩小、关联搜索候选，以及左右侧栏分别收起／恢复均已检查；卡片保持在实际阅读区内。未选择关联候选或保存数据。主要交互验收完成；其他主题及完整保存流程未复测，临时窄容器检查不代表所有真实分栏尺寸均已覆盖。详见本日收尾记录。
