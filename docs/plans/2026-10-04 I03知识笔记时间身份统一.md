# I03 知识笔记时间身份统一

Task: 统一阅读模式与实时预览的记录时间识别。
Task type: 展示判定修复。
User scenario: 知识笔记中记录时间右对齐，原文、普通正文和代码里的相似文字保留原样。
Current behavior: 编辑器仅识别带来源属性、##笔记段内的独立时间；阅读模式对任意单独EM时间加样式。
Reproduction: 测试库新开已有知识笔记的临时标签，仅调用原生renderer.set渲染内存夹具（不改view.data或Markdown）。##笔记及##原文中的时间在修复前均styled=true。
Root-cause evidence: 原生getSectionInfo返回全文及准确的0基行号；阅读函数仅正则检测EM文本，没有源段落身份约束。
Target behavior: 阅读模式通过getSectionInfo复用knowledgeNoteTimeLines，与实时预览使用同一判定；支持CRLF；来源信息缺失或section不可用时不猜测。
Completion criteria: 统一判定测试与完整verify通过，原生阅读夹具复现前后差异，真实文件内容不变。
Scope: knowledge-note-time-display、main的上下文传递、纯识别函数CRLF及两项回归测试。
Explicitly excluded: 模板和时间值、已有笔记迁移、来源身份、其他33条诊断、发布。
Affected data and files: 三源码文件、生成main.js、测试和记录；无持久化字段或写入路径变化。
Automated verification: 12项定向测试及230项完整verify通过（普通／strict类型、生产构建、主程序语法）。覆盖多条时间、原文、围栏、缺来源、无section、多行段落、非EM/多子节点、CRLF及重新判定移除旧样式。
Obsidian verification: 重载测试插件后，原生单条夹具笔记时间true、原文时间false；多条夹具两条记录时间true，正文及引用原文时间false，围栏内容保持代码。读取真实Markdown与原view.data逐字相同；临时内存渲染已还原，临时标签关闭，图书库／原EPUB／12条笔记侧栏和开发工具状态恢复。实时预览共用的纯判定已测试，但本轮没有新建实时预览编辑夹具，不冒称两种UI完整实机矩阵通过。未覆盖所有主题／手改模板。
Failure handling: section不可用不应用特殊样式，不写入或迁移内容。
Rollback: 撤销本轮三源码差异并重新构建；保留I01/I02及用户原改动。
Documents to update: 本任务卡、增量清单、03、04。
