# 插件原生风格与生态审查

日期：2026-10-01。性质：源码审查与优化建议，不是实现或跨主题验收。

后续进展：第一批字号、统计入口和评分控件已实施，范围及实际验证见 [原生风格统一第一批](2026-10-01%20原生风格统一第一批.md)。第二批弹窗焦点及卡片边界已实施并通过主要场景验收，见 [第二批记录](2026-10-01%20原生风格统一第二批.md)。工具栏、选文菜单键盘与主要交互收尾见 [收尾记录](2026-10-01%20原生风格统一收尾.md)。本轮界面优先项已完成，重复样式维护问题转入结构审查；其他主题兼容矩阵仍未穷尽。以下为审查当时记录。

## 结论

插件已经沿用 Obsidian 的设置页、菜单、主题颜色和 Markdown 渲染，但尚不能称为完全统一。主要差距是部分固定字号、自绘控件的键盘行为、浮动卡片的尺寸约束，以及多轮覆盖样式带来的维护成本。应继续收敛现有界面，不新增一套视觉系统。

## 已有基础

- `src/settings.ts` 使用 PluginSettingTab、Setting、FuzzySuggestModal。
- `src/main.ts:137` 监听 vault rename；注册阅读视图、命令、文件菜单与设置页。这比仅模仿外观更符合宿主工作方式。
- `src/EpubReader.tsx:176` 使用 MarkdownRenderer；书籍管理和笔记操作已经使用原生 Menu。
- 统计和卡片已有大量主题字号、文字与背景变量。阅读背景应继续跟随主题，只调整标记对比度。

## 建议的统一基准

- 普通界面文字、次要信息、小标题采用宿主主题字号变量；数字强调只在统计摘要使用。
- 使用主题背景、边框、圆角和阴影；高亮保留语义颜色并适配深浅色，不修改阅读区域底色。
- 控件、内容区和卡片分别统一间距。统计与书架对齐外边距，词卡与笔记卡沿用已认可的内部密度。
- 原生 API 能满足的菜单、提示、文件选择优先复用。自绘卡片保留阅读专用功能，同时补足焦点、键盘和容器尺寸行为。
- 保留 Markdown、块链接、改名跟随等现有知识库机制；本次不改变数据格式、统计口径和持久化路径。

## 推荐实施顺序与验收

第一批只统一字号、返回按钮和工具按钮规范，并修复评分键盘操作。第二批验证浮动卡片边界和自绘窗口焦点。最后逐组件整理重复 CSS。

分别检查默认浅色/深色、用户当前主题、放大 UI 字号、窄分栏、侧栏展开/收起和仅键盘操作。外观一致不能替代这些检查。

本轮没有修改实现，没有运行测试，也没有进行新的 Obsidian 实机或跨主题验收。保留当前统计未提交改动；不修改日常库，不提交或发布。
