# EPUB 路径自动跟随

Task: EPUB 改名或移动后关联阅读记录。
Task type: 状态迁移与恢复。
User scenario: 在 Obsidian 中整理 EPUB 文件后继续阅读。
Current behavior: rename 只刷新书架，路径键与来源链接不更新。
Reproduction: main.ts 无 EPUB rename 迁移，data/index 使用文件路径键。
Root-cause evidence: bookInitLocations、bookProgress、bookBookmarks、readingStats、bookHighlights 和封面键均含旧路径。
Target behavior: 路径键迁移，CFI／ID／时长不变；旧来源链接通过别名定位，既有读书笔记通过显式路径关联，不重建。
Completion criteria: 测试覆盖正常迁移、保存失败回滚、部分保存恢复、冲突与连续改名；测试库事件验收。
Scope: 运行期间单个 EPUB 文件改名／移动，开放阅读器暂停并重新加载。
Explicitly excluded: 日常库修改、发布、外部离线移动识别、Markdown 笔记改名、文件夹整体改名、正文格式和统计功能扩展。
Affected data and files: 阅读状态、索引、词条来源与封面缓存；新增 bookPathAliases/bookNotePaths 及 pending/book-path-rename.json。Markdown 不写入。
Automated verification: npm run verify；纯服务与内存存储测试，失败／冲突／恢复／重新读取。
Obsidian verification: 只测试库，使用新建的临时副本；不改现有书籍。
Failure handling: 写前恢复记录、读回校验；失败回滚并保留记录，停止后续保存，重载时尝试完成恢复；冲突保留现场。
Rollback: 回退源码并构建；正式使用后不能仅删除别名，否则旧来源链接失效。
Documents to update: 03 改动日志、04 接续说明、02 后续想法。

## 验收结果

2026-10-01：156 项自动验证通过；测试库临时副本实际改名、打开中移动、旧链接、位置／书签／进度／时长／高亮／笔记路径／自定义封面与重载读回通过。临时数据清理后书架恢复原计数，控制台关闭。真实故障未注入，失败／损坏／回滚覆盖仅内存测试；范围外场景未验收。
