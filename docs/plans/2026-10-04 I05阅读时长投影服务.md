# I05 阅读时长投影服务边界

Task: 将统计保存后笔记时长投影从界面移至服务／宿主适配。
Task type: 最小职责整理。
User scenario: 自动阅读累计先保存统计，再同步读书笔记reading_time。
Current behavior: EpubView直接累计统计并processFrontMatter；统计保存失败不投影，投影失败仅警告。
Reproduction: 检查saveReadingStats、ReadingStatsService.flush、getOrCreateBookNote及既有异常处理。
Root-cause evidence: EpubView直接写Markdown权威存储；BookNoteService尚无时长投影入口。
Target behavior: 统计服务负责成功后的投影顺序，BookNoteService及操作适配负责笔记解析／创建与元数据写入；既有错误语义不变。
Completion criteria: 统计失败不投影、投影失败保留统计、累计总秒数、无待存秒数不投影、缺失笔记行为保持，完整verify及隔离运行验收。
Scope: 自动统计保存用例、笔记服务及操作适配、定向测试。
Explicitly excluded: 手动补录流程、统计算法／字段迁移／重算、真实用户数据故障注入、提交发布。
Affected data and files: reading_time仍是投影，readingStats仍为权威；本轮不主动改真实笔记或统计。
Automated verification: npm run verify通过普通／strict类型检查、238项测试、生产构建及main.js语法。新增4项统计服务用例验证成功顺序／保存失败／投影失败／无待存秒数；新增4项用内存Obsidian替身打包真实操作适配的测试，验证改名关联、累计时长格式及其他属性保留、已关联笔记缺失不创建替代、未关联仍新建、元数据写失败。diff检查通过。
Obsidian verification: 测试插件重载成功，图书库及原EPUB标签恢复。在加载后的真实EpubView.saveReadingStats入口以隔离内存对象运行：成功calls=[save,project:65]、pending=0、total=65；统计失败calls=[save]、拒绝、pending=5、total=60；投影失败calls=[save,project:65]、只警告、pending=0、total=65；无待存秒数calls=[]。没有把夹具或失败注入真实统计／笔记；应用正常运行／重载仍可能按既有规则保存真实阅读时间，不承诺data.json逐字节不变。开发工具关闭，原图书库／目录侧栏状态恢复。实际磁盘元数据故障不破坏真实文件测试，覆盖来自真实适配的内存替身；真实长时间阅读／关闭／重开全链路本轮未额外执行。
Failure handling: 统计保存异常仍抛出并保持pending；笔记投影异常仅报告，不回滚成功统计。
Rollback: 撤销本轮差异并重建；保留前四项。
