# 移除阅读器外查词功能

Task: 按用户要求完整移除阅读器外的查词、翻译与词卡。
Task type: 产品范围缩减。
User scenario: 普通Markdown编辑／阅读时不受插件词卡干扰，查词仅服务EPUB阅读。
Current behavior: DOM鼠标抬起和全局CodeMirror扩展自动选词弹卡，已收藏词条在Markdown标记／悬停显示。
Reproduction: 实机双击Markdown标题Procrastination自动弹出离线卡，临时关闭开关后不弹。
Root-cause evidence: main注册registerGlobalMarkdownFeatures，global-markdown同时注册DOM监听及编辑器扩展；没有其他消费者。
Target behavior: 删除整个外部入口与实现、专属样式及旧开关，保留EPUB查词／翻译／词卡与既有词条。
Completion criteria: 完整verify、Markdown编辑和阅读选词无卡、EPUB离线查词正常、词条数据不变。
Scope: main注册／旧字段清理、global-markdown模块、types、专属CSS、当前README与规则。
Explicitly excluded: 删除词条／Markdown／知识笔记、修改EPUB功能、调用AI、提交发布、日常库。
Affected data and files: 移除旧设置字段（下次正常保存不再包含），不新增迁移、不写词条索引。
Automated verification: npm run verify、剩余消费者扫描、diff检查。
Obsidian verification: Markdown编辑及阅读双击选词、插件重载、词条内存对比、EPUB离线菜单和释义。
Failure handling: 删除注册不会触发词条保存；既有服务失败路径保留。
Rollback: 仅恢复本任务外部模块／注册／字段／CSS及文档，重新构建；不撤销前几批整理与封面恢复。
Documents to update: 01／03／04、README、当前清单。
