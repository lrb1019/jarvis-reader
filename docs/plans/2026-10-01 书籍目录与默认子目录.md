# 书籍目录与默认子目录

Task: 书籍根目录和三个默认输出目录统一配置。
Task type: 设置与目录创建。
User scenario: 用户指定 EPUB 文件夹，使用或自定义 Reading Notes、Knowledge Notes、Cover。
Current behavior: 没有书籍目录设置；笔记、知识、封面分别配置，默认名称不一致；书架扫描整个仓库。
Reproduction: 设置源码 DEFAULT_SETTINGS 与三个独立目录控件；LibraryApp.loadBooks 未限制目录。
Root-cause evidence: 没有根目录字段及生成子目录、统一保存创建流程。
Target behavior: 选择／输入根目录生成三个英文默认子路径，可编辑后显式保存；书架按根目录筛选。
Completion criteria: 默认联动、目录创建、持久化与重载、自定义路径、旧配置保留及失败保护通过。
Scope: 设置表单、目录服务、书架扫描及新笔记／封面缺目录创建。
Explicitly excluded: 移动既有书籍／笔记／封面、迁移缓存、发布及日常库部署。
Affected data and files: data.json 的四个目录设置；显式保存时创建指定空目录。既有内容及位置／索引不变。
Automated verification: npm run verify；默认路径、目录边界、嵌套创建、冲突、失败重试与保存回滚测试。
Obsidian verification: 测试库表单默认联动、自定义 Ideas、保存创建、loadData 读回、插件重载保留、自定义目录截图。
Failure handling: 全部路径先验证，文件占用拒绝；创建或保存失败提示，保存失败恢复内存配置；已创建空目录保留可重试，不自动删目录。
Rollback: 恢复源码并重新构建；既有配置不自动改，验收临时配置已恢复。
Documents to update: 改动日志、接续说明。
