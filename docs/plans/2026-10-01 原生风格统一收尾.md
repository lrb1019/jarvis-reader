# 原生风格统一收尾

日期：2026-10-01。仅在 Obsidian-test 实施；当前版本保持 1.4.1，未提交、推送或发布。

## 任务边界

Task：完成风格审查的界面优先项与交互收尾。
Task type：展示与键盘可访问性。
User scenario：在书架切换布局与筛选；通过右键选文菜单打开笔记；缩小阅读区或调整侧栏后继续查看卡片。
Current behavior：工具栏混用内联图标，选文菜单缺少进入焦点与方向键行为；固定字号和容器约束已在前两批修正。
Reproduction：源码与测试库实际菜单、窄窗口检查。
Root-cause evidence：选文容器只有 toolbar 语义和 Escape，未绑定菜单方向键；工具栏六处内联 SVG，窄布局仍按一行展开。
Target behavior：使用宿主图标、主题字号与紧凑工具栏；菜单支持键盘；实际容器变化不裁切卡片。
Completion criteria：本批自动检查、菜单键盘与打开笔记、筛选及布局切换、窄窗口检查完成；兼容矩阵未覆盖项单独登记。
Scope：书架工具栏、选文菜单、减少动态效果、前两批实机收尾。
Explicitly excluded：结构清理、重复 CSS 合并、数据格式与统计算法、发布及日常库部署。
Affected data and files：EpubReader、LibraryApp、styles.css、生成 main.js 与管理记录；不修改笔记正文或索引。
Automated verification：最终 npm run verify 的结果见改动日志；新增边界测试包含在 171 项测试中。
Obsidian verification：以下为 Obsidian 1.13.7 测试库实际结果。
Failure handling：原保存与失败处理不变；本轮不发送翻译请求或执行真实删除。
Rollback：恢复本轮来源文件后重新构建；不得覆盖此前已有统计改动及用户数据。
Documents to update：本记录、审查进展、第二批记录、项目规则、改动日志与接续说明。

## 完成内容

- 前两批的主题字号、紧凑统计返回、可聚焦评分按钮、资料弹窗焦点循环和卡片实际尺寸约束已经完成。
- 书架搜索、清除、筛选、网格、列表与设置图标使用 Obsidian 图标接口；补充按钮名称、布局选中状态和筛选展开状态。工具按钮 28px；窄窗口搜索与操作分行，避免撑出边界。
- 选文右键菜单打开聚焦第一项，方向键循环、Home／End定位、Escape／Tab关闭；保留原按钮动作与选文数据。菜单使用 menu／menuitem 语义，删除项文字统一为“删除”。
- 浮动卡片和有关控件响应 prefers-reduced-motion，关闭非必要动画或过渡。未实际切换系统减少动态效果设置。

## 实机证据

1. 真实鼠标选取现有划线后右键：初始聚焦复制，Down到AI翻译、End到删除、Home回复制；Escape关闭。再次打开后方向键到笔记，Return打开原片段笔记卡，原文保持。未调用AI或删除。
2. 笔记卡实际拖动与手动缩小通过；左右侧栏分别收起、恢复后卡片仍处于阅读区内。关联搜索出现两个匹配候选、文字及路径正常，无关联写入。
3. 阅读设置临时360×600px阅读区与放大UI字号：正文UI计算为17px，当前主题深色背景与文字正常，面板完整位于容器内且无横向溢出。预览类名、尺寸和变量已恢复。
4. 图书库临时360px宽及放大UI字号：输入17px，工具按钮约28px，标题区 clientWidth／scrollWidth 同为280px，无横向溢出；临时设置已恢复。
5. 最终构建重载后筛选正常展开／关闭，列表切换显示两本书，恢复网格后封面与百分比显示正常。开发者工具已关闭。
6. 前两批资料窗口 Tab／Shift+Tab首尾循环、Escape关闭返回入口；300×400px阅读区的词卡与笔记卡约268×368px，长词卡可滚动到底，已记录于第二批。

## 收尾判断与限制

本轮已确认的风格优先项和主要交互场景已收尾。仍不能声称完全适配所有主题：其他第三方主题、全部字号与尺寸组合、系统减少动态效果实际开关尚未覆盖。真实评分保存、补录保存和删除未在本次展示验收中重复操作，不能标为本轮实机通过；其服务逻辑未改。

重复覆盖样式与组件职责属于下一阶段结构审查，先记录证据再分批处理，不在风格任务中顺手清理。代码结构审查框架已登记；本轮尚未开始全面结构调查。
