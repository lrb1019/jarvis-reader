# 选文操作菜单调整

- Task：将选中后的入口统一为横向工具栏，分离离线查词与 AI 翻译。
- Task type：阅读交互修正。
- User scenario：用户希望选词和选句都能立即复制、划线或记录笔记，不必先右键，也不被自动释义卡挡住。
- Current behavior：`handleTextSelected` 只触发 `autoLocalOnly`；非单词选文明确不打开菜单，只有 contextmenu 打开操作。单词命中词典后清除菜单，造成两个流程互斥。
- Reproduction / Root-cause evidence：用户句子截图与源码分支一致；修改前选句无菜单，自动查词和菜单状态互相清除。
- Target behavior：选中任意非空正文后显示横向“复制／AI 翻译／划线／笔记”；单个英文单词额外显示“离线查词”。不再自动打开释义卡。查词和 AI 由各自按钮明确触发；右键保留同一操作作为备用。
- Completion criteria：单词与句子自动菜单、横向布局、离线及 AI 路由隔离、笔记选文正确、清空选区及 Escape 关闭、翻页关闭旧菜单。
- Scope：复用 `pendingHighlightMenu`、现有复制／高亮／笔记／翻译及收藏服务；新 `reader-selection.ts` 只负责翻译选项和界面边界计算。当前高亮的已有编辑／删除仍走原服务及确认。菜单使用原生按钮，鼠标按下保持选区；按实测尺寸限制位置，窄区内横向滚动。
- Explicitly excluded：新增翻译提供商、字典来源、自定义动作、自动调用 AI、词汇资产迁移、Markdown 格式及定位改造；不复制 Readest 全部功能。
- Affected data and files：`EpubReader.tsx`、CSS、纯规则模块、测试、严格类型门禁及生成 bundle。没有新增配置字段，不改 EPUB、笔记或索引的数据格式。只有用户明确点击保存时，原服务才写入高亮／笔记／词条。
- Creation / Display / Reload / Editing / Deletion：选区临时产生菜单，取消或翻页销毁，不持久化；右键复用同一菜单。已有高亮身份继续复用，删除仍由既有确认流程；新划线和笔记保存沿用现有服务。重载后临时菜单关闭，书籍和保存状态沿用原逻辑。不存在本批独立内容文件或迁移。
- Failure handling：离线未命中显示明确错误，提供主动 AI 按钮，不自动发起网络请求；两类查询均使用同一请求序号，过期结果不能覆盖新的选区。AI 配置错误或失败显示在原词卡中，不阻断其他操作。存储异常继续使用既有保存及恢复机制，本批未注入新的磁盘故障。
- Automated verification：`npm run verify` 通过 139 项测试、普通／严格类型检查、构建和 bundle 语法检查；新测试覆盖 localOnly 与 forceAi 路由以及右／下边界和窄区定位。差异空白检查通过。
- Obsidian verification：重载后在实际 EPUB 文档创建 Selection，使用 epub.js 原生选区事件链，选句自动出现四项菜单，选词出现五项，computed flex-direction 为 row，选中本身不调用翻译。点击离线查 productivity 得到词典结果，调用记录只有 localOnly；点击 AI 使用测试替身验证 forceAi 和结果呈现，没有发送外部请求。笔记编辑弹窗打开，规范化空白后摘录与选文一致；Escape 和清空选区均关闭菜单。还观察到用户选择 exercise 时实际工具栏五项可见。测试替身与临时对象撤销，阅读 CFI 恢复；未写入测试笔记或词条。
- 未验证：真实 AI 提供商端到端、全套中文／双栏／滚动／跨页选区、移动端触控、窄区实际拖动、复制剪贴板、新增划线与笔记的写入／删除全流程、长延迟网络返回的专门运行实验。新模块不改变存储；已有核心测试继续通过，不能据此声称新菜单下所有写入流程都已实机验收。
- Rollback：撤回本批选区入口、翻译路由和 CSS 后重建；没有用户数据迁移或删除。
- Documents to update：改动日志、接续说明。
- Reference：Readest 官方 [Translate & Lookup](https://www.readest.com/docs/translate) 将翻译放在选文工具栏中。这里只借鉴交互组织，使用本插件既有离线词典与用户主动 AI 请求。
