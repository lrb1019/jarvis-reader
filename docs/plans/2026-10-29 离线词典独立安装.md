# 离线词典独立安装

发布状态：本功能已随GitHub 1.4.6于2026-10-29正式发布；词典作为独立ZIP附在同一Release。

## 任务边界

- Task：将 ECDICT 作为用户主动导入的独立资源分发。
- Task type：功能与发布打包调整。
- User scenario：市场／BRAT 只安装三个运行文件，用户之后安装离线词典；已有词典不重装。
- Current behavior：旧运行代码只读固定 `.obsidian/plugins/jarvis-reader/dictionaries/ecdict`，缺目录返回空结果，容易误报“未收录”；ZIP 携带词典，市场三个文件安装路径不携带它。
- Reproduction：在无词典的内存适配器查询英文单词；对照发布打包清单。
- Root-cause evidence：原 `lookupLocalDictionary` 对缺失分片继续返回 null；原 `release-package.mjs` 只生成含词典的完整 ZIP。
- Target behavior：已有旧目录继续读取；设置显示安装状态；选择独立 ZIP 后校验并导入；全部成功后切换，失败继续使用原词典。
- Completion criteria：新装缺词典有明确提示；旧词典可查；真实包导入、重载和离线查询成功；坏包／失败保存不替换；包不混入用户数据。
- Scope：词典服务、设置入口、查询接入、词典打包、发布附件、中英文使用说明及针对性测试。
- Explicitly excluded：自有源码许可证选择、完整第三方依赖审计、市场申请、版本发布、全项目路径整改、手机支持认证、日常库部署。
- Affected data and files：词典资源与当前插件的 dictionaries/installed.json；不改词条侧车、笔记或书籍索引。
- Automated verification：内存故障测试、完整 verify、两个 ZIP 清单及真实词典导入自检。
- Obsidian verification：只在 Obsidian-test，用真实 ZIP 导入、重载并在 EPUB 右键离线查词；不调用 AI、收藏或外网发音。
- Failure handling：显式区分未安装／不完整／损坏／未命中；不自动调用 AI。临时目录失败时清理，原目录保留。
- Rollback：旧词典文件不覆盖；每次导入保留旧安装目录和上一份安装指针。指针替换失败恢复原记录，重启遇到替换中断可从 bak 恢复。插件源码可回退本批；旧版仍读取原 ecdict 目录。
- Documents to update：README 中英文、第三方资源声明、发布流程、改动日志、接续说明。

## 实现

1. 新包固定为 26 个字母 JSON、dictionary.json 和 LICENSE。清单记录来源、内容版本、每片字节数和 SHA-256；版本由词典内容哈希决定，不随插件版本重复升级。
2. 最大 ZIP 64 MB、单片16 MB、总清单128 MB，ZIP 只允许固定文件名；按分片流式解压，并以清单字节数为上限，校验哈希、UTF-8、JSON 和词条结构。校验只能检测完整性，不证明发布者身份，README 要求只用官方 Release。
3. 导入到独立 import-UUID 目录，逐片保存回读校验后写安装指针。旧版 ecdict 和历史导入目录保留，不影响用户词卡与笔记。安装记录／导入资源已加入 Git 忽略，避免把测试资源加入源码。
4. 设置“词典与词卡”显示状态、导入按钮及发布页链接。仅在用户选择本地 ZIP 后读文件和安装，不自动联网。
5. 缺词典时抛出明确离线错误；用户主动选择 AI 时，缺失离线补充元数据不阻塞 AI 返回。此分支仅代码核对，未请求真实 AI。
6. 复用已安装的 JSZip 3.10.1，显式声明直接依赖，未升级或新增另一套 ZIP 库。其 ZipObject.internalStream 方法由本地源码确认存在，声明缺失的类型局限于词典解压适配处。
7. 插件 ZIP 只含三个运行文件及第三方声明，词典独立 ZIP 和 .sha256 由发布工作流附加。当前未改版本或公开资源，README 明确与已发布 1.4.5 的区别。
