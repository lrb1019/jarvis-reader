## 3. 设计原则

1. 工具栏、按钮、菜单和笔记界面继续跟随 Obsidian。正文允许必要的阅读调整，首轮不新增主题系统。
2. 常用项在阅读器内就近调整、即时预览；高级项收起。复用同一设置模型与保存队列，不产生两处互不一致的参数。
3. 每个可调项显示真实值，支持恢复默认。恢复当前书设置与修改全局默认明确区分。
4. 改字体、字号、宽度、单双页或打开侧栏后，尽量保持原文锚点；允许重新分页，不用页码不变作为要求。
5. 不修改原 EPUB 或 Markdown 正文。不能通过删除用户内容解决排版问题。
6. 先有具体样例和预期，再改样式。无法确认原因的问题先诊断，不以大量 `!important` 覆盖代替查证。

## 4. 阶段 R0：现有参数与阅读基线

- 类型：诊断与一致性修复。
- 场景：拖动字号／行高滑块，正文在部分区间不再按数值变化。

- 数据：读取旧设置时按统一规则生效，不为本任务批量重写用户配置；明确何时保存规范化值。
- 检查：边界值、无效旧值、滑块显示值与正文对应；保存、关闭、重载结果一致。

建立后续共用的临时书籍样例：中文正文、英文长段落与长词、标题与列表、诗歌／缩进、图片与宽表格、链接／脚注。优先使用已有合法测试资源，不故意破坏真实书籍。

完成条件：范围不一致已复现并修正；现有滚动／单双页和位置恢复的当前状态有记录。未发现的故障不能写成已修复。

## 5. 阶段 R1：正文宽度、留白和分屏适配

### 5.1 用户体验

- 常用设置增加正文最大宽度、左右留白，避免大窗口一行过长。
- 窄窗口自动缩小有效宽度；用户偏好值保留，窗口变大时恢复，不把临时尺寸写成新偏好。
- 延用已有单页／双页选项；宽度不足时合理退回单栏，不生成挤压的双栏。
- 上下边距首轮保持合理默认，需要时再放入高级设置。

### 5.2 实现方法

先核对当前 EPUB 引擎的容器、分页栏宽和 resize 过程。最大正文宽度与双页的单栏宽度须定义清楚，不能仅给 body 加 max-width 导致引擎页宽失配。

通过现有视图尺寸变化通知，必要时在正确容器使用 ResizeObserver。尺寸变更节流；保存当前 CFI 锚点，等待重新布局完成后恢复，避免每次通知重复跳转。取消过期恢复请求，插件关闭时清理监听。

文件入口：`src/EpubReader.tsx`、`src/EpubView.ts`、`src/theme.ts`、`src/types.ts`、`src/settings.ts` 与相关样式。设置通过现有保存队列保存，界面不直接写 `data.json`。

### 5.3 验收

13 英寸窗口正常宽度、窄分屏；打开／关闭 Markdown 笔记和侧栏；连续拖动分隔条；单页／双页／滚动模式；长词、图片、表格。核对文字未被裁切、无异常横向溢出、位置没有跳回旧进度，原划线仍覆盖正确文字。

回退：撤回布局代码与匹配构建，新增设置字段可保留为不使用的值，不恢复整份旧配置覆盖其他设置。

## 6. 阶段 R2：字体、原书样式与段落

### 6.1 分层设置

| 层级 | 首轮内容 | 行为 |
| --- | --- | --- |
| 常用 | 字号、行距、段间距 | 数值明确，即时预览 |
| 字体来源 | 跟随 Obsidian／保留原书字体 | 首轮不做字体文件导入；“保留原书”不保证设备有该字体 |
| 段落排版 | 保留原书布局／自定义段落 | 自定义才启用段距与对齐覆盖 |
| 高级 | 左对齐／两端对齐、必要时英文断词 | 先验证引擎与语言支持，缺能力不显示无效选项 |

首字缩进、字距、词距、最小字号和字重暂缓；真实样例证明必要时再增加。不要把 Readest 的全部控件复制过来。

### 6.2 实现要点

- 默认延续现有用户外观，提供显式恢复原书样式选项，避免升级突然改变全库排版。
- 覆盖规则尽量针对普通正文。保留标题层级、粗斜体、等宽代码、诗歌、表格和脚注的语义差别。
- 切回原书模式时真正撤销插件覆盖，而非叠加另一层样式；检查多次切换和切书后没有残留。
- 字体缺失时回退到可显示的字体；图片和特殊内容不因整体规则被拉伸。
- 布局模式与颜色分开，暗色主题仍需保证文字可读；不以保留原书字体为理由同时放弃颜色适配。
- 字体和段落更新复用 R1 的锚点恢复机制，不在不同控件分别实现跳转补丁。

验收：中文、英文、混排、列表、代码、诗歌与图表；保留／覆盖往返；断词不污染复制文本、选文内容或 CFI；重启后设置与位置正确。未支持特殊排版必须明确记录。

## 7. 阶段 R3：翻页、选文与就近操作

### 7.1 优先检查已有交互

- 拖动选文不能触发翻页；选文结束后不误触页面点击。
- 点击链接、脚注、已保存词语、划线和卡片按钮不能同时翻页。
- 编辑笔记、输入设置时，方向键只作用于输入控件。复用现有键盘隔离，不重建一套全局监听。
- 弹窗与卡片打开后，翻页快捷键如何处理要一致；关闭后焦点返回合适位置，不丢失选区或阅读位置。

对每项先记录实际复现。正常行为只做回归，不因为列入计划而强行重写。

### 7.2 可增加的少量控制

点击正文翻页提供开关；桌面端默认优先保护选文，最终默认值结合当前用户习惯和样例确认。已有键盘与导航按钮继续可用。

滚动模式的“按屏翻动”可保留约一至两行重叠文字，帮助接续；使用实际行高估算且限制范围，不改变普通触控板自然滚动，不新增复杂像素设置。先核对现有操作入口是否存在，再决定接入位置。

测试覆盖拖动、双击选词、连续点击、链接点击、输入焦点和异步卡片；Obsidian 中实际验证鼠标与触控板。未测移动端不得宣称手势兼容。

## 8. 阶段 R4：单书偏好与简洁阅读信息

在排版规则稳定后实施，避免过早扩大配置迁移。

- 默认所有书继承全局阅读设置，特殊书籍可设置局部覆盖。
- 只保存与默认不同的必要字段；“仅本书”和“设为默认”动作明确，不因一次预览修改所有书。
- 通过 `BookStateService` 和现有设置队列管理，不在 React 组件里直接写状态文件。
- 核对当前书籍身份与路径迁移方式；原文回跳方案若已处理书籍移动，应复用结果。
- 删除局部偏好只恢复继承，不能清除阅读进度、书签或划线。
- 页脚优先章节与阅读进度，可隐藏。章节进度与全书进度明确标注，重排后的页码不能冒充纸书页码。
- 详细阅读统计先保持现状，后续再讨论；本阶段不新增预计读完时间、时钟、电量和阅读目标。

验收两本书：一书自定义、一书继承；修改全局值、恢复本书默认、重启、书籍移动。局部配置保存失败时提示，不能悄悄写到全局。
