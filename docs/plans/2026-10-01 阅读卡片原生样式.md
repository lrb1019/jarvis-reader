# 阅读卡片原生样式

Task: 读书笔记浮窗与词卡向 Obsidian 原生风格看齐。
Task type: 局部展示样式。
User scenario: 阅读中查看多条笔记、关联或已收藏词条。
Current behavior: 笔记双层圆角边框和虚线框；词卡彩色胶囊标签、重标题与固定阴影。
Reproduction: 用户三张截图；测试库现有两条笔记与 battle 词卡。
Root-cause evidence: CSS content-frame 边框、note-card 虚线边框、固定阴影，EpubReader/global-markdown 重复内联彩色标签；无数据或解析问题。
Target behavior: 主题圆角／阴影／文字层级，笔记细分隔线，词卡中性紧凑标签与较轻标题。
Completion criteria: 自动验证通过、实际卡片显示内容与原操作入口；不改数据。
Scope: styles.css 和现有标签展示类；生成 main.js。
Explicitly excluded: 持久化、统计、阅读背景色、操作条件、窗口尺寸与定位逻辑。
Affected data and files: 无权威数据修改；EpubReader.tsx、global-markdown.ts、styles.css、main.js。
Automated verification: npm run verify，168 项测试、类型、构建、语法通过；最终字体调整只涉及 CSS，diff 检查。
Obsidian verification: 测试插件重载与现有 style 加载；现有双笔记卡截图确认，battle 词卡内容／标签／模糊／来源截图确认。实测圆角 8px、标题 15px/600、标签无边框。预览词卡临时调整 DOM top 以显示全部内容，不持久化；关闭后清除。
Failure handling: 沿用既有逻辑，无数据迁移或新增写入。
Rollback: 恢复本任务样式及标签类，重新构建。
Documents to update: 改动日志、接续说明。

未验证：深色与其他主题、关联操作、编辑／删除／发音／外部 AI 调用、拖拽与滚动。本次查看靠近底部的词卡出现既有定位估算高度不足问题，showWordHoverCard 按 190px 而非实际内容高限位，另列后续问题；未扩展本次范围。
