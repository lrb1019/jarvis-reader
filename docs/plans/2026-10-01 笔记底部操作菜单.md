# 笔记底部操作菜单

Task: 笔记编辑删除移到底部时间旁的常驻省略号菜单，适当减小页边距。
Task type: 展示与入口。
User scenario: 正式笔记卡须有可发现入口，但标题旁两个图标太抢眼。
Current behavior: 标题右侧常驻编辑删除，内容宽 400px。
Reproduction: 用户截图和测试库现有笔记。
Root-cause evidence: renderHighlightNotes 将两个按钮放在标题行；CSS 限宽形成较大侧边留白。
Target behavior: 时间旁低对比度常驻 ⋯，点击原生菜单编辑／删除；内容最大宽度 440px 居中。
Completion criteria: 自动验证与真实菜单显示／编辑进入通过。
Scope: EpubReader.tsx、styles.css、生成 main.js。
Explicitly excluded: 删除确认策略、持久化、数据、词卡、全卡顶部操作。
Affected data and files: 无权威数据修改，原编辑删除回调保持。
Automated verification: npm run verify。
Obsidian verification: 测试库重载、现有笔记底部菜单和编辑入口，不保存修改或删除。
Failure handling: 既有 Notice 和删除确认保持。
Rollback: 恢复本任务源码和样式并构建。
Documents to update: 改动日志、接续说明。

## 验证结果

168 项测试、类型、构建、语法通过；diff 空白检查通过。测试库现有双笔记窗口重载后截图确认标题行无编辑删除、底部时间旁省略号可见、左右留白减小。原生菜单 AX 两项“编辑”“删除”，点击编辑进入测试1001输入，取消后回到查看。未保存编辑或删除任何笔记；深色／其他主题、极窄窗口与键盘未复测。窗口留开、控制台关闭，日常库未改，未提交发布。
