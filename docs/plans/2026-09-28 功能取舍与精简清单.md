# 功能取舍与精简清单

## 1. 状态与目标

2026-09-28 编写，基于本地 1.3.4 源码和本次产品定位讨论。智能指令的源码退出与自动验证已完成，尚待 Obsidian 实机回归；其余清单仍是待实施方向。用户已明确移除智能指令、全部记忆与复习功能，并允许清理复习记录和掌握状态。单词本已确定按第 1.1 节精简；详细阅读统计先保持现状，累计阅读时长、图表和历史阅读记录均不改，之后再决定是否调整。阅读相关能力明确保留。

核心目标：阅读 EPUB，保存 Markdown 读书笔记，关联已有笔记，从笔记返回原文。英文辅助只帮助理解阅读内容，不发展成独立英语学习系统。

与 [阅读笔记实施方案](2026-09-28%20阅读笔记融入%20Obsidian%20实施方案.md) 配套。前者补齐主流程，本文减少干扰和不必要维护，两者分别实施、分别验收。

## 1.1 最新决定：英语辅助仅保留三项

本节记录用户后续明确决定，取代下文先前“单词本待决定”的建议。功能尚未实施。

第三方离线词典导入于 2026-09-28 经用户明确暂缓，仅在项目待办中保留思路，不属于本方案实施范围。离线查词继续使用内置 ECDICT，不增加词典格式或系统词典适配。

1. **离线查词**：继续使用当前离线词典，查询时显示释义，查询不自动保存。
2. **主动大模型翻译**：保留现有 API 翻译，单词、短语和长句均可查询；长句不能收藏。此服务与将移除的 Claudian 智能指令分开。
3. **手动保存单词与短语**：点击保存才写入本地词条数据；阅读中再次遇到时，轻量标记并允许点击查看已保存释义，不自动铺开答案。卡片保留取消保存和更新释义，避免只能保存不能管理。

移除独立单词本页面、词条列表、专用词条侧边栏和对应命令，不建立替代的查词历史页面。不实施自动查词历史、CEFR 分级、Word Lens 自动释义或任何新的学习系统。记忆复习及其记录、掌握状态仍按已确认范围移除。

首轮“别处再次遇到”按本插件不同书籍中的阅读内容实现，不扩展为自动扫描或改写整个知识库。已有 Markdown 词卡兼容行为需核对，不能因视图删除破坏笔记。词形与短语识别沿用现有能力并通过样例检查。

### 实施方法

- 核对 `src/main.ts` 的词条视图与命令，`src/word-book/`、`src/sidebar/WordSidebarView.ts` 的专用浏览界面，`src/EpubReader.tsx` 的保存、匹配和浮动卡片。共享代码核对调用后处理，不按目录整体删除。
- 服务层与界面共同限制只能保存单词和短语；使用明确内容类型，不仅依靠字符长度，不依赖 AI 自动判断保存资格。
- 保留本地词义、来源与词形数据；去掉掌握状态筛选，已保存单词短语均可提示。不同词形和重叠短语用临时样例验证，不误改阅读划线。
- 旧布局引用已移除页面时安全关闭或转回阅读，不能留下空白与报错。
- 已有长句收藏的删除未获明确指示：保留原数据，不参与新的单词短语提示，不自动转换为笔记；后续清理需列明数量、影响与恢复办法。

### 验收

离线可查词；查词不自动增加收藏；单词短语主动保存并重启后，在另一处出现可点开；长句可翻译但所有入口均不能新增长句收藏；取消保存后提示消失；正常划线不受影响；无单词本与复习界面；验证保存失败、损坏文件、旧布局和旧词卡兼容。运行 `npm run verify`，完成对应 Obsidian 实机检查，未测项明确记录。

## 2. 取舍明细

| 单词记忆复习 | 已确认直接移除 | 删除复习会话、评分、计划和掌握状态操作，不保留启用开关 | 清理复习记录与掌握状态；保留暂未决定删除的词义、来源和收藏内容 |
| 复习算法参数 | 随记忆复习一起删除 | 移除难度、间隔倍率、复习发音等专属设置 | 清理专属配置，普通查词发音保留 |
| 单词／短语收藏 | 已确认保留手动保存 | 本地保存，阅读中再遇可点击查看 | 不自动保存查询，不新增长句收藏 |
| 独立单词本、词条侧边栏与列表 | 已确认移除 | 只在阅读中就近查看词义 | 保留单词短语收藏，处理旧布局 |
| 已保存词卡自动标记 | 保留再遇点击所需的轻量提示 | 在正文标出已保存词卡，便于再次查看释义；与手动划线分别处理 | 当前筛选依赖掌握状态，删除该状态后必须显式调整，不能意外扩大标记范围 |
| 离线词典自带考试标签 | 可在展示层折叠或隐藏 | 首屏突出词义和发音 | 保留词典原始数据、词典资源和许可，不把标签当作独立功能删除 |
| 详细阅读统计 | 先保持现状，后续再讨论 | 阅读进度、位置恢复、累计时长和图表照常提供 | 阅读记录保留；复习次数和复习时长随复习系统移除，不能混删 |
| 书架装饰、额外图表 | 不新增 | 继续提供找书、搜索、继续阅读和基本状态 | 现有必要筛选和排序保留 |
| 全局 Markdown 翻译 | 核对现有入口后作为可选能力 | 优先保证书内查词翻译，仓库其他笔记不默认增加操作干扰 | 不扩大文本发送范围，已有偏好不静默覆盖 |
| 离线查词、发音、选句翻译 | 保留，轻量呈现 | 遇到不懂的单词、短语或句子能即时理解，然后继续阅读 | 单词优先离线；外部请求仍由用户明确触发 |
| 阅读设置 | 保留常用项，后续按实用性分组 | 字号、行距、内容宽度、主题、翻页方式易于找到 | 不批量重置个人阅读参数 |
| 阅读、划线、多条笔记、关联、来源、数据恢复 | 保留并优先完善 | 形成完整的阅读与笔记使用过程 | 不因精简牺牲保存、备份和恢复能力 |

注意：“隐藏”保留实现和维护成本，只减少默认干扰；“移除”需要清理入口、调用和依赖。不能把隐藏菜单说成已移除功能。用户已明确删除记忆复习，因此不再采用隐藏后观察的建议。

## 3. 第一项任务：移除智能指令

### 3.1 范围与依据

- 类型：功能退出。
- 场景：选文或笔记窗口调用第三方指令。
- 当前行为：有指令设置和 Claudian 适配，近期已有因输入框变化而调整适配的记录。
- 目标：Jarvis Reader 不再提供第三方指令调用；正常阅读、笔记与翻译继续可用。
- 依据：用户明确表达不再需要，适配产生持续维护成本。
- 排除：不移除独立翻译服务，不处理外部 Claudian 插件、其他插件的选文上下文功能或用户 Skill 文件。

### 3.2 操作顺序

1. 搜索 `smartCommands`、指令执行入口、`claudianBridge` 和 `smart-command-core` 的所有调用，记录完整清单。检查选文菜单、笔记弹窗、设置、类型、默认值和测试。
2. 先移除选文菜单、笔记窗口菜单、设置项、命令注册和默认配置，再清理仅被这些入口使用的执行、Claudian 桥接、类型和测试代码。无法确认是否共享的函数先查调用，不直接删除整段相关代码。
3. 迁移时清理旧 `smartCommands` 配置：先生成一次性可恢复备份，再删除该字段；插件此后不读取、保存或透传它。核对设置保存不会影响其他未知字段。
4. 保留既有 Markdown 中的 AI 内容及其解析。取消指令生成能力不意味着删除历史内容或其显示能力。
5. 检查 `aiSections` 同时承载关联文章等内容的事实，不按字段名称整体删除。关联功能必须继续工作。
6. 构建生成 `main.js`，同步修改相关说明，不手工改构建产物。

### 3.3 验收与回退

- 自动：类型检查、相关测试、生产构建和 `main.js` 语法检查，统一执行 `npm run verify`；清理仅针对已退出功能的失效测试，保留共享功能测试。
- 实机：无 Claudian 时插件正常加载；选文可划线、写笔记、查词和翻译；已有多条笔记、关联及 AI 内容显示正常；打开旧设置和重启不报错。无需向外部服务实际发送内容来证明指令已移除。
- 失败处理：发现共享依赖或内容无法读取时停止删除对应代码，缩小改动再查原因。
- 回退：恢复本任务之前的源码和匹配构建，旧配置仍可用。不要恢复整个 `data.json` 覆盖用户后来新增的设置。

## 4. 第二项任务：移除全部记忆与复习

### 4.1 已确认范围

删除复习会话、间隔重复算法、难度评分、复习计划、掌握／未掌握操作、复习统计及专属设置。不保留重新启用开关。用户已允许删除对应记录与掌握状态，不再要求先观察使用情况。

单词本按第 1.1 节精简，详细阅读统计按现状保留。本任务只清理学习状态，暂时保留词义、原文来源、收藏内容、普通发音、即时查词和翻译。

### 4.2 实现顺序

1. 核对 `src/word-book/ReviewSession.tsx`、`SpacedRepetition.ts`、`WordBookStats.tsx`、`WordBookApp.tsx` 及全部调用，删除复习入口、会话、算法和定时器。统计组件可能同时展示收藏信息，不能按文件名整体删除。
2. 从设置、默认值、类型、词条卡和阅读器移除复习参数及掌握状态操作。特别检查 `EpubReader.tsx` 中按 `mastered` 筛选正文标记的代码。
3. 自动标记与收藏按第 1.1 节实现。移除掌握字段后，所有已保存单词短语统一提供轻量点击提示；升级说明告知原先已掌握词条也可点击查看，不自动展开释义。该设置变化不影响用户手动划线。
4. 编写显式版本迁移，列清实际学习字段与存储位置。候选包括 `mastered`、复习次数／时长、间隔、难度、到期时间等；以源码为准，不能按名字模糊删除。共享统计仅清理复习部分，保留阅读部分。
5. 在测试夹具验证后再迁移真实配置与词条文件。执行前报告对象、记录数量、影响和恢复方式；用户本轮已授权清理学习数据，无需再次询问同一决定。授权不扩展到其他知识库或共享数据中的收藏正文。
6. 使用现有原子保存、校验和一次性迁移备份；损坏文件停止迁移，不覆盖为空数据。迁移幂等，失败保留原文件，跨文件部分完成时可诊断并重试，不静默重建学习记录。
7. 核对旧工作区中的复习页面，升级后关闭或转到可用页面，不留空白和异常；正常保存不得重新写回已经删除的学习字段。

### 4.3 验收与回退

- 自动：新安装、旧配置升级、缺文件、损坏文件、保存失败、部分迁移失败、重复执行、重启后字段不复活；词义、来源、收藏和阅读统计在迁移前后一致。
- 实机：复习、评分和掌握操作全部消失；查词、发音、翻译、划线、笔记、阅读位置和仍保留的收藏能使用；标记行为符合升级说明。
- 运行 `npm run verify`。只删除复习专属测试，共享词条和数据安全检查保留。
- 回退：保存匹配旧版的数据快照，说明恢复旧复习能力需要该快照。功能删除不意味着立即删除恢复备份；不依赖清空整个词库回退，不覆盖迁移后新增的收藏和笔记。

## 5. 第三项任务：默认界面减负

此任务在原文回跳、复制引用的入口确定后执行，避免重复调整菜单。

- 主要操作：划线、写笔记、关联、查看来源／返回原文。
- 英文辅助：查词、翻译；仅提供单词短语的手动收藏。
- 次级操作：独立词条列表与复习不再提供；详细阅读统计保持现状。
- 设置按用途集中为阅读、笔记与文件、英文辅助；备份恢复等工具保留可发现入口。先画或实现可撤回的布局样例，不按分类数量强行合并。

使用 13 英寸正常宽度和窄侧栏检查：常用操作是否容易找到，长文本是否遮挡，核心流程能否完成。图标数量减少本身不等于体验通过。

新默认值只作用于缺省设置；已有明确的个人设置继续保留。若需要迁移一个曾经自动写入的默认值，先确认能否区别用户选择；无法区别时保持旧值并给出设置入口。

## 6. 与核心开发的顺序

1. 单独完成智能指令退出，验证核心流程未受影响。
2. 按主方案完成 A0／A1 原文回跳和 B 复制引用。
3. 独立移除全部记忆复习及其记录，词汇收藏按第 1.1 节精简，详细统计暂不改动。
4. 统一默认界面，同时继续主方案 C 知识笔记来源与命名。
5. 样例确认后再做主方案 D 的笔记正文格式调整。

每项独立验收和记录，不在同一提交中同时删除第三方适配、改变索引和迁移 Markdown。实施前按项目规则读管理文档、核对 Git，保留本轮已经存在的文档改动。
