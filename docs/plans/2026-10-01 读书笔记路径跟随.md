# 读书笔记单文件路径跟随

Task: Obsidian 内读书笔记改名／移动后自动更新关联，并修正用户已移动的两份笔记。
Task type: 路径同步。
User scenario: 移动 Markdown 读书笔记，不增加设置、弹窗或复杂搜索。
Current behavior: EPUB 路径已跟随，Markdown notePath／bookNotePaths 不跟随，书架显示缺关联提示。
Reproduction: 两份真实笔记移入 Reading Notes，旧路径不存在，3／5 个高亮块仍存在于新笔记。
Root-cause evidence: vault rename handler 原先只处理 EPUB；索引与设置仍保留旧 Markdown 路径。
Target behavior: 监听单个 Markdown rename 事件，匹配旧关联路径，更新 bookNotePaths 与高亮 notePath 并保存，正文与稳定身份不变。
Completion criteria: 改名、跨目录移动、连续操作、持久化重载、删除保护和失败恢复通过；原两份笔记关联修正。
Scope: 复用 BookPathService 事务／恢复流程扩展 note 操作，原队列；知识笔记按稳定 source_block 识别以避免源笔记移动后重复提升。
Explicitly excluded: 文件夹整体改名／移动、离线外部操作、全库自动搜索、设置／普通操作弹窗、批量改写 Markdown 正文／既有知识笔记来源链接。
Affected data and files: data.json bookNotePaths、highlights.json notePath；原 Markdown、块 ID、quote／comment 内容权威、位置、书签、统计、封面及词条不改变。
Automated verification: npm run verify；笔记路径跟随、内容与身份保持、失败回滚、恢复重载、冲突拒绝、无关笔记忽略、知识笔记防重复。
Obsidian verification: 核对真实笔记全部 3／5 个块 ID 唯一匹配后修复关联；临时笔记连续 A→B→Moved/C 的真实 rename 事件，内存与重载读回检查、内容不变、删除不清空关联、高亮／记录保留。
Failure handling: 复用已验证 journal 校验、回滚和启动恢复，不吞失败；正常不弹窗，存储错误暂停保存并保留证据。
Rollback: 恢复源码并重新构建；已修正的真实笔记路径可从当前仍存在的目标查证，恢复记录按既有流程处理。
Documents to update: 改动日志、接续说明、后续想法。
