# Q03 初始化进度跳动修复

Task: 避免定位表生成期间的章节估算百分比先显示／保存，再跳成准确进度。
Task type: 实机确认计算来源切换的限定修复。
User scenario: 正常打开／重开书籍，定位表生成前后保持阅读位置和进度一致。
Current behavior: 同CFI生成前保存23%章节估算，生成后保存12%locations计算；准确0%也会被旧回退规则覆盖。
Reproduction: 实证记录同CFI、locations0→132、saved0.22727→0.122137；纯函数与受控generate回归。
Root-cause evidence: getReaderProgress的来源切换，以及ensureReaderLocations失败不触发进度刷新。
Target behavior: 生成中无准确来源时只显示章内页码、不产生待保存进度；完成后读当前定位刷新，失败／空结果降级，准确0保留。
Completion criteria: 回归先失败再通过、完整verify、实机重开／翻页关闭恢复并记录来源事件；限制明确。
Scope: progress.ts初始化阶段／回退规则、EpubReader生成回调失效保护与卸载ref清理，测试与文档。
Explicitly excluded: 改CFI、取最大百分比、重写全书算法、旧data.json批量修正、Q01／Q02扩大、提交发布。
Affected data and files: progress.ts、EpubReader.tsx、progress.test.ts、生成main.js；不手工改真实进度或书籍。
Automated verification: pending／成功／失败／空结果／无生成器／0%／迟到回调／最新定位。
Obsidian verification: 实际初始化事件采集只记录匿名位置、locations数量与百分比；打开／翻页／关闭重开。
Failure handling: 生成失败记录非阻断警告，结束pending并刷新当前降级进度；同rendition不反复生成。没有生成器沿用旧降级。
Rollback: /private/tmp/jr-q03-progress-before.ts、jr-q03-reader-before.tsx、jr-q03-tests-before.ts保留本任务前状态；生成产物由回退后重建。
