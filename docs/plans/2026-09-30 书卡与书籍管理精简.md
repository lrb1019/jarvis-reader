# 书卡与书籍管理精简

Task: 移除展开书卡与独立详情页，将管理操作放到三个点菜单。
Task type: 界面简化，保留管理入口并补录阅读时长。
User scenario: 单击选中，双击打开；不放大，封面下方显示进度和菜单。
Current behavior: 点击放大书卡，阅读／详情按钮重复，详情页同时承载管理和内容展示。
Reproduction: 原网格选中使用绝对定位和 200% 宽度；列表点击导航 detail。
Root-cause evidence: LibraryApp.tsx 的 selectedGridBook 样式分支和 renderDetail 路由；原时长仅展示，没有编辑控件。
Target behavior: 固定尺寸书卡，菜单提供编辑阅读资料、更换封面、补录阅读时长、删除。
Completion criteria: 不再有详情路由和展开卡片；管理入口可打开，单击尺寸稳定、双击进入 EPUB，验证通过。
Scope: 图书库网格／列表交互、阅读资料弹窗、封面入口、统计补录服务。
Explicitly excluded: 日常库部署、发布、实际用户数据删除、笔记和词汇存储改动、EPUB 元数据规范化。
Affected data and files: LibraryApp、styles.css、reading-stats-service、测试；删除详情专用展示组件。仅用户触发保存时写现有封面缓存／Markdown frontmatter／readingStats。
Automated verification: npm run verify；补录日期和分钟校验、保存与重新读取、失败回滚、自动计时并发、异常统计拒绝写入。
Obsidian verification: 仅 Obsidian-test；检查菜单／资料／补录窗口、选中尺寸和双击打开。不对真实数据执行补录、封面替换或删除。
Failure handling: 补录失败恢复内存并显示错误；沿用既有资料和封面保存路径。已有资料保存不是整表事务，本任务未改为整表提交。
Rollback: 回退本任务源码并重新构建；补录为按指定日期累加，不修改原阅读位置或进度。
Documents to update: 03 改动日志、04 接续说明；README 正式版本说明留待下次发布对齐。
