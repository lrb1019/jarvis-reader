# 阅读卡片间距

Task: 收紧阅读笔记浮窗间距，让短笔记保持集中。
Task type: 局部 CSS。
User scenario: 打开现有多条短笔记，窗口较宽时内容与右侧图标、时间拉散。
Current behavior: 内容铺满宽度，时间右对齐；正文 1.55／1.65 行距，条目 gap 6px。
Reproduction: 用户截图与现有双笔记卡。
Root-cause evidence: 实机正文 13px／20.15px 行高；note-card-text 的 white-space pre-wrap 被 Markdown HTML 渲染节点继承，节点间格式化换行生成额外空行。content-frame 无最大内容宽度，时间右对齐。
Target behavior: 内容居中且最大 400px，正文行高 1.45，相邻正文段落 6px；条目上下 8px，条目之间不额外增加 gap，时间左对齐；收紧原文至标签及列表间距。
Completion criteria: 自动检查通过，测试库现有卡片实机检查。
Scope: 浮动阅读笔记卡样式。
Explicitly excluded: 菜单、编辑删除按钮、词卡、数据、窗口尺寸和定位。
Affected data and files: styles.css；无权威数据修改。
Automated verification: npm run verify、diff 空白检查。
Obsidian verification: 当前测试库加载磁盘样式，查看现有双笔记与计算样式。
Failure handling: 无新增保存或数据处理。
Rollback: 恢复本任务 CSS 并加载。
Documents to update: 改动日志、接续说明。

## 验证结果

npm run verify 168 项测试、类型／严格类型、构建与语法通过；最终 CSS white-space 修正后 diff 空白检查通过。测试库仅加载已有 style 的磁盘 CSS，无插件重载或内容写入。现有双笔记（第二条为用户粘贴的段落与列表）截图确认集中显示；计算内容宽约 400px、正文行高 18.85px／1.45、相邻单行列表间距 18.85px、时间左对齐、Markdown white-space normal。取消 HTML 格式化换行的空行，不修改笔记文字、Markdown 或显式换行。

窗口保持打开便于用户看效果，控制台关闭。未验证其他主题／深色、极窄窗口、编辑／删除／持久化操作；本次仅 CSS，不改词卡或数据。日常库未改，未提交发布。
