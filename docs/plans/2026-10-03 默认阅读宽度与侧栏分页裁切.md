# 默认阅读宽度与侧栏分页裁切

Task: 增大默认正文宽度，消除侧栏开关时右侧相邻页短暂露出。
Task type: 阅读界面布局修复。
User scenario: 单页阅读，打开／关闭 Obsidian 侧栏。
Current behavior: 默认宽度760px；容器变宽时，旧分页可能在右侧露出相邻栏。
Reproduction: 用户报告；测试库确认单页模式、epub-container采用100%宽度，适配器等待100ms后重排。
Root-cause evidence: reader-resize.ts 延迟100ms；本地 epub.js Stage 使用100%宽度，manager.resize同步清除旧视图再更新布局；旧iframe分页尺寸在重排前不随容器立即改变。
Target behavior: 默认960px；重排前只展示原分页宽度，重排后开放新宽度。
Completion criteria: 参数校验、选区保护、关闭清理通过；测试库裁切宽度在重排前保持、重排后更新。
Scope: reader-settings默认值、reader-resize分页边界回调、EpubReader界面适配、CSS和针对性测试。
Explicitly excluded: 不改单双页选择、不改翻页和定位逻辑、不修改第三方插件、不修改日常库或发布。
Affected data and files: 仅界面与默认值；已有用户宽度不迁移、不覆盖；未配置／恢复默认使用960px。
Automated verification: npm run verify；检查新增边界更新时序与已有选区延期回归。
Obsidian verification: 待重载并记录侧栏开关与实际分页裁切。
Failure handling: 沿用原重排与选区延期；没有新增存储事务。
Rollback: 撤回本次默认值、回调、样式与测试并重新构建；无需恢复用户内容。
Documents to update: 改动日志与接续说明。
