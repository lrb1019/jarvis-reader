# Q01 书签并发保存修复

Task: 修复书签较早失败回滚覆盖较新状态。
Task type: 已确认数据一致性问题的限定修复。
User scenario: 连续添加／删除书签，某次存储失败后继续使用。
Current behavior: 底层保存排队，但上层操作同时修改整张map，失败回滚覆盖新map，后续快照可能带入失败书签。
Reproduction: 真实SettingsSaveQueue＋内存host受控失败，见待诊断问题实证记录Q01。
Root-cause evidence: commitBookmarks回滚前，下一保存已捕获含两书签的快照；最终内存为空、保存快照含两书签。
Target behavior: 服务内串行完整读取、去重／修改、保存和回滚；失败操作回滚后下一操作读取最新状态，失败不阻断后续队列。
Completion criteria: 先复现回归失败，修复后真实队列并发测试、完整verify通过，并记录实机检查限制。
Scope: BookStateService.addBookmark／removeBookmark／clearRuntimeState共享局部操作队列；相关回归与文档。
Explicitly excluded: 全局保存锁、位置／进度算法、Q02／Q03、改名事务、真实存储故障注入、发布提交。
Affected data and files: book-state-service.ts、专属测试、构建main.js；不手工改data.json、Markdown或索引。
Automated verification: 同书／异书、去重、失败后重试、添加／删除／运行状态清理交错，重载快照一致性；npm run verify。
Obsidian verification: 测试库加载与已有书签显示／定位；故障用隔离内存，禁止损坏真实存储。
Failure handling: 当前操作错误仍返回调用者；队列尾捕获仅确保后续继续，不吞当前错误。
Rollback: /private/tmp/jr-q01-service-before.ts和jr-q01-tests-before.ts是本任务前快照，只回退本任务差异；产物由回退后构建生成。
Documents to update: 本记录、03／04、02、整改清单、实证记录。

状态：限定修复、自动验证与运行构建内存验收完成；真实书签写入／删除未本轮执行。

边界：clearRuntimeState也替换bookBookmarks整张map，必须和书签操作用同一服务队列。saveLocation／saveProgress维持原有行为；跨服务改名与其他保存事务不宣称已全局串行化。clearRuntimeState对位置／进度的并发回滚不是本次已确认书签故障范围。
